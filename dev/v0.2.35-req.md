# PPPaint v0.2.35 要求定義

- [ ] ペンで描いているときの不自然な枠線を出さない。
- [ ] 選択・移動で一部を囲って動かしたとき、範囲内をラスタ画像として切り離して移動する（確認回答：ペン・図形も含む見えている内容全体）。
- [ ] スポイトはドラッグ中に色を採取して可視化し、離した地点で最終決定する。
- [ ] 情報隠しを四角の▼メニューの塗りつぶし有無へ統合する。
- [ ] 吹き出しの形状調整点を増やし、上部のテキスト編集欄を表示し、文字がはみ出す場合は本文枠を拡張する。一般的なツールを参考に編集箇所を増やす。
- [ ] 矢印の種類と塗りつぶし有無を▼メニューで選ぶ（確認回答：線の矢印・両端矢印・太いブロック矢印・陰影のある立体矢印の4種類）。
- [ ] 円の輪郭／塗りつぶし、番号の丸／四角／囲みなしと塗りつぶし有無を▼メニューで選ぶ（確認回答：この構成で進める）。
