# v0.1.0 リファクタリング実装・報告

## 2026-09-08 実施計画

要求の正本は既存の `../v0.1.0-req.md`。今回の追加実装・報告は本ファイルに記録する。
既存の配布ロケール設定、リリーススクリプト、キャプチャーの未コミット変更は保持し、今回のコミットに含めない。

1. R1（CP-REQ-002/003/016）: 保存経路を共通のトランザクションへ分離。失敗時の既存ファイル保持、成功時の置換を実ファイルで検証する。
2. R2（CP-REQ-004/016）: 塗りつぶしの探索を整理し、同一画素の重複登録と不要な中間配列を削減。連結性・境界・入力画素保持を検証する。
3. R3（CP-REQ-002/006）: 調査で見つかった「開く」キャンセル時の浮動選択確定を修正。ファイルを選んだ後に未保存確認・編集確定を行う。

開始時のCoreテスト: 174件成功。各フェーズでテストとDebug x64ビルドを実行してから日本語でコミットする。

## R1 実施報告
- 画像・プロジェクト保存を `DocumentFileWriter` へ集約。Windowsの書き込みトランザクションを使用し、書き込み完了時だけコミットする。
- 画像コーデックは形式検証後にストリームを切り詰め、先頭へシークしてから保存する。未対応形式を渡すと既存データが消える問題も修正。
- 実ファイルへの途中失敗、短いデータでの置換、プロジェクト往復を検証。Imaging 8件成功、Core基準174件成功、Debug x64ビルドは警告0・エラー0、diff検査成功。
- トランザクション非対応の保存先では保存エラーとして扱い、既存ファイルを直接切り詰める代替処理は行わない。実UIの全操作、クラウド保存先、実ディスク不足は未検証。

## R2 実施報告
- 結果リストを探索キューとして再利用し、画素の訪問記録を候補登録時に移動。重複する候補のスタックを除去した。
- 直接塗りつぶす処理は内部リストを使用し、結果配列へのコピーを省略。公開APIの返却型と4方向の連結規則は維持する（探索順は保証しない）。
- 256×256の一色領域で、変更前は探索の割当が2,949,968 bytesとなり回帰テストが失敗。変更後は1,048,576 bytes未満で成功。斜め接続、行末折り返し、重複画素、元画像保持、同色置換も検証。
- 全185件（Core 177、Imaging 8）成功。Debug x64ビルドは警告0・エラー0。品質ゲートのキャプチャー索引53件・ハッシュ・diff検査成功（テストとビルドは別途実行後、スクリプトは-SkipBuildで実行）。
- 実画面のマウス操作全般と最大サイズでの実操作は未検証。メモリ検証は上記サイズの割当量を対象とし、全サイズでの応答時間を保証しない。

## R3 実施報告
- 「開く／インポート」でファイル選択を先に行い、キャンセル時は即座に復帰する。選択前に浮動選択が確定される問題と、不要な保存確認を解消。
- ファイル選択後の未保存確認・読み込み処理は維持した。差分の制御フローを確認し、全185テスト成功、Debug x64ビルドは警告0・エラー0、diff検査成功。
- 修正済みDebug実行ファイルでメインウィンドウ「無題 - ChunPaint」の生成と終了コード0を確認。
- ダイアログの実操作によるキャンセル回帰は未検証。手動確認: 浮動選択を移動中の状態から「開く」を選び、ファイル選択をキャンセルした後に選択を移動・取消できることを確認する。
