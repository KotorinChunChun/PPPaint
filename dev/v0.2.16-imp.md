# PPPaint v0.2.16 実装計画・報告

## 設計

ツール別の数値（幅/文字サイズ/効果強度/不透明度）を保存し、選択対象の数値表示とは分離する。ツール切替時にそのツールの既定値を復元し、既存オブジェクトの選択だけでは既定値を上書きしない。旧形式の共有設定を移行し、破損・未知の項目は安全に既定値へ戻す。ユーザーの回答により、番号は画像ごとに1から開始し、次番号を永続化しない。

消しゴムは画像画素に揃えた四角の実消去範囲と、その同じ範囲を表示するプレビューへ統一する。1ドットでは指定画素を背景色で完全に置換し、透明背景では完全に透明へ戻す。画像/図形/マスク/効果/Undo/Redo/保存へ共通の描画経路を使う。太さ1のペンの画素精度は維持する。

ペン/スポイトは独自に作成した鉛筆/スポイトカーソルを使用し、画像の操作点とホットスポットを合わせる。消しゴムはネイティブのプラスを隠し、実範囲の四角い輪郭を表示する。パン/端の切取/ハンドル操作では既存のシステムカーソルを優先する。カーソル表示をコピー/PNGへ焼き込まない。

Microsoftの著作物利用条件は https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions を確認した。Paintの素材を抽出・同梱する許可は確認できないため流用せず、既存の独自生成資産を改善する。標準カーソル一覧は https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.input.inputsystemcursorshape を参照。

## フェーズ

- P1: 設定の独立保存/移行、消去描画と四角プレビュー、独自カーソルの資源生成と配線。Core/画素回帰とReleaseビルドを実行してコミット。
- P2: 隔離設定でツール切替・プロセス再起動による保持をUIA確認し、通常デスクトップ側の専用テストウィンドウで実入力とカーソルを確認する。配布版を検証し、旧版の未保存作業を保持して通常デスクトップ側へ起動する。認証/pushは行わない。

## P1 結果

ScreenshotToolPreferencesをCoreへ追加し、Version2のTools辞書を保存する。旧共有値を各ツールへ初期化し、明示変更した項目だけを最新ファイルへマージする。選択表示ではモデルを更新せず、切替時に最新の既定値を取得する。消しゴムの幅は整数へ正規化し、通常ペンの小数幅は維持する。次番号はユーザー回答により文書ごとのままとした。

四角のFootprintと端点正方形の凸包を用いたSweepをCoreへ実装。Winding幾何を一度だけAliased/Copyで塗り、クリップを維持してBlend/Antialiasingを復元する。プレビューも同じ範囲関数を使う。旧円形消去の経路は除いた。

既存の独自カーソル生成を拡張し、鉛筆/スポイトの先端にホットスポットを置き、32/48/64pxを同梱した。透明カーソルでプラスを隠して四角い消去範囲だけを表示する。パン・サイズ変更のシステムカーソルは維持する。Nativeのリソース読込と生成PNGの形を確認した。

Release警告0・エラー0、Core275/Imaging63、全338件成功。1ドット消去の再現4件は修正前失敗・修正後成功。追加設定11件/消去15件と既存回帰を確認。git diff --check成功。

## P2 検証・修正

publishでカーソルDLLがContentと明示資源の両方に登録される重複を検知し、標準Contentの配布に統一して欠落チェックを残した。配布版の実アプリではNamed resource APIが読込に失敗したため、専用の数値IDとロード済みモジュールを使うAPIへ変更し、カーソル破棄後にモジュールを解放する。資産名の大小変更だけでは解消しなかったため採用しなかった。消しゴムでキャンバス端を切り取る時に消去範囲が同時に出ないよう、実際のカーソル用途と表示条件も合わせた。

通常デスクトップ側の隔離UIAで、ペン1・消しゴム16・矢印5・文字40・吹き出し18・番号32・ぼかし19・モザイク22・透かし65の9設定を往復し、プロセス終了→同じ設定先での再起動後も全て一致した。旧共有値7の移行、消しゴム1.5→2の表示、次番号7が再起動後1になることも確認した。

専用文書の実入力検証は前面確認に失敗し、マウス送信前に停止。WinSta0/Defaultと入力デスクトップDefaultを読み取り確認したが、GetForegroundWindow=0で実入力/画面撮影は未実施。テスト文書はUIAで元へ戻して通常終了した。カーソルDLL内の3資源を別途展開し、鉛筆/スポイトの先端3,28と透明カーソル0,0を確認した。実表示の検証と資源解析を区別する。

配布版はff77b341ec04ed252499f37b837e91c99c0ebf3cからpublish。旧v0.2.15 PID20500の管理窓口を照合して安全なstopを要求したが、未保存画像によりrefusedだったため維持した。v0.2.16は設定を `%LOCALAPPDATA%/PPPaint/profiles/editor` へ分離し、既存設定を初回だけコピーしてPID21740で起動。IsOffscreen=false・通常デスクトップ側のUIAから「無題 - PPPaint - v0.2.16」を確認し、起動したまま残した。前面表示の確認はできていない。再起動用Start-PPPaint.cmdを同梱し、次版も同じ設定を引き継ぐ。認証/pushや未保存作業の破棄は行っていない。
