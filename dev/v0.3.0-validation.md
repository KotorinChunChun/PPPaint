## 検証中の修正

- UI AutomationのTogglePatternでもツールを選択できるよう、Checkedイベントを接続した。
- 文字の変更に合わせて枠を自動拡張し、入力欄が一時的に空になった場合の数値も既定値で扱う。
- `Window.Closed` の取消を尊重し、未保存確認前の描画資源破棄・アプリ終了を防いだ。WinUIのイベント順序は [Microsoftのissue](https://github.com/microsoft/microsoft-ui-xaml/issues/11053) と実画面の取消動作を確認した。
- 管理窓口の移譲で、旧パイプの解放前に新窓口がUIスレッドで再試行する問題を修正した。処理をTask.Runで分離し、例外後の連続再試行に待機を設けた。
- 自動操作はメニューの閉じるアニメーション、コピーの非同期完了を待ってから次の操作へ進む。コピー処理中の終了要求は文書保護のため取り消される。
