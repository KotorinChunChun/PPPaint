# PPPaint v0.2.28 実装計画・報告

## 計画

中央の全体図をUIから除き、同じ大きさの８方位拡大図を配置する。各拡大図の位置はダイアログ開始時の元画像座標へ固定し、数値変更・ドラッグ・ドラッグ終了でも候補境界への再センタリングを行わない。倍率の明示変更だけが表示範囲を変更する。初期の余白割合は、2026-11-02のユーザー回答により各軸80%／20%（角は80×80）で確定した。実装済みの配置と一致するため、コード変更は不要。

描画は元画像を一度だけレンダリングして使用し、候補サイズで再レンダリングしない。元画像とキャンバス外の背景を固定して描き、候補境界と切り取り部分の暗い表示だけを更新する。候補原点の変化は全８ビューの座標変換へ同量反映し、元画像の見える位置を維持する。範囲外へドラッグしても自動で画像を追従させない。

Coreで初期配置・８ビューの固定・1pxドラッグと連続操作、Imagingで元画像の画素位置・透明画像・切り取り表示を検証する。UIAの現行サイズ画面検証を８ビューへ更新し、中央図の不在と数値変更前後の元座標固定を確認する。Release全検証後に配布し、旧版の未保存作業を維持して最新版を起動する。１フェーズで検証と記録を完了してコミットする。

## 実装・検証結果

全体図を生成しない８ビューへ変更した。全ビューを100×100で統一し、元の画像座標から各辺の外側20%／内側80%になる初期範囲を求める。中央段の中央にはビューを作らない。数値変更やドラッグ終了後も元画像の位置は同じで、明示的な倍率変更だけが表示範囲を変える。

元画像は一度だけレンダリングして保持する。候補寸法ごとの再描画を外し、同じ元画像と外側背景へ切り取り側だけの暗いオーバーレイと境界を重ねる。候補原点の移動は全８ビューへ同量反映し、画像・透過の市松の位置を固定する。境界の入力は処理済みイベントも受け、捕捉失敗時には操作を始めない。解放時の最終座標も移動と同じ処理へ通す。

Releaseビルドは警告０／エラー０、Core388＋Imaging98＝486試験成功、失敗／skip０。新規Core３試験で初期80/20、各倍率・全８方向の元座標固定、複数回ドラッグ後の線の位置と再ヒットを検証。新規Imaging２試験で８方向×96/144/192dpi×切り取り／拡張／原点変更の保持画素、透明画像の１回合成、切り取り部分の暗さ、外側背景の固定を検証した。`artifacts/qa-v0.2.28/rendered/initial.png`・`cropped.png`・`expanded.png` はGPU試験の比較画像として目視確認したもので、ウィンドウ撮影とは区別する。

ソース版UIA（PID29468、`artifacts/qa-v0.2.28/ui/preview-validation.json`）で全体図不在、８拡大図、数値変更前後の固定元範囲、倍率、差分、適用／Undo、取消を確認した。

実入力試験の初期失敗では、座標設定だけではWinUIへ移動イベントが届いていなかった。診断で押下と捕捉は正常、移動座標だけが開始位置のままであることを確認した。試験を対象窓・前面確認付きの絶対座標マウス移動へ変更した。診断用処理は製品コードから除去済み。

修正後の実入力試験（PID12460、`artifacts/qa-v0.2.28/absolute/preview-validation.json`）は成功。右辺は押下中159px→解放後158px、左辺はさらに1px切り取り157px、外側へ2pxで162pxを確認。ドラッグ後の全８ビューの元座標固定、本体キャンバスの未変更、適用／Undo、取消も成功した。専用窓の `trim-preview.png` と `expanded-preview.png` を撮影・目視確認し、中央の全体図がないことと、画像・外側背景を保った境界表示を確認した。専用プロセスは終了済み。クリップボードは変更していない。

自己完結型win-x64配布物は `artifacts/release/v0.2.28/win-x64`。配布版UIA（PID7480、`artifacts/qa-v0.2.28/release-ui/preview-validation.json`）でも全体図不在・８方向固定・差分／倍率・適用／Undo・取消が成功した。製品コードの一時診断処理が残っていないこと、PowerShell構文、差分空白、変更範囲の旧識別子不在も確認した。

旧版の数値設定だけを `editor-v0.2.28` へ複製して最新版を別起動した。PID18960の実行パス・管理応答のPID／版／要求ID・ready=trueを照合し、UIAで `無題 - PPPaint - v0.2.28` とIsOffscreen=false、８拡大図と全体図の不在を確認。サイズ変更画面を表示した状態で残した（`artifacts/qa-v0.2.28/startup.json`）。旧版PID27484／23640と利用者画像を変更していない。並行起動用は `Start-PPPaint-Parallel.cmd`。公開・pushは行っていない。
