# PPPaint v0.3.0 要求一覧

2026-10-29 ユーザー指示と確認回答。

- 右上のフィードバックとアカウント機能を削除する。
- タブを廃止し、画像ごとに別ウィンドウで編集する。
- 多角形、星、吹き出し、ハート、雷などの図形と自由選択を削除する。
- 画像サイズ変更は左下の寸法表示から、拡大縮小表示は右下のバーから実行し、重複ボタンをツールバーから削除する。
- レイヤー機能とAI生成機能を削除する。
- 写真補正、背景除去、グラデーション、特殊ブラシ、一括変換、印刷、壁紙設定などを削除してスクリーンショット編集に用途を絞る。
- 通常のペン、消しゴム、矩形選択、回転、反転を残す。
- Ctrl+Vによるクリップボード画像取り込みとファイルのドラッグ＆ドロップに対応する。
- トリミングを提供する。
- 矢印、四角、丸、直線に対応し、色と線の太さを変更できるようにする。
- テキストと番号マーカーを追加する。
- 情報隠しに不透明な塗りつぶしを用意し、出力画像へ焼き込む。
- 描いた注釈を後から選択、移動、サイズ変更、削除できるようにする。
- 元に戻す、やり直す、コピー、PNG保存を提供する。
- 蛍光ペン、表示の拡大縮小、画像の縦横連結をすべて追加する。
- 中央の画像を大きくし、上部に主要ツールと色・太さ・文字サイズをまとめる。
- 直前の色や太さを記憶する。
