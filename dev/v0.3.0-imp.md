# PPPaint v0.3.0 実装計画・報告

## 設計と変更対象

旧MainWindowは多数の写真・レイヤー・タブ機能が相互依存しているため、画面と編集制御を置き換える。WinUI/Win2D、画像コーデック、画像処理と起動引数の基盤は再利用する。旧版の要求書・履歴とユーザーの画像は保持する。

- P1: 単一画像と編集可能な注釈のモデル、画像連結、トリミング、Undo/Redoを追加し、単体試験する。
- P2: 旧画面・不要なアプリ機能を削除し、単一画像ウィンドウ、コンパクトなツールバー、注釈再編集、入出力、独自ファイル選択、設定記憶を実装する。複数ウィンドウを独立管理する。
- P3: Core/Imaging試験、Releaseビルド、隔離設定と架空画像による実画面検証を行い、資料を更新する。

注釈は画像とは別の編集オブジェクトとして保持するが、利用者向けレイヤー操作は持たない。コピー・PNG保存は同じ描画経路で注釈と不透明な情報隠しを焼き込む。PNGを再度開いた後は焼き込み済み画像として扱う。画像の縦横連結は元ファイルを変更しない。

画像を開く・貼り付ける操作は既存の作業を上書きせず、新規ウィンドウで扱う（未編集の空ウィンドウは再利用）。画像ごとに保存状態・選択・履歴・ズームを所有する。終了時は未保存確認を行う。

OS標準ファイル選択には依存せず、ContentDialog内でフォルダー・ファイルを選択する。情報隠しの色は常に不透明とし、蛍光ペンの半透明とは独立させる。

## 検証方針

モデルの履歴、境界、連結順序、注釈変換を単体試験する。Win2Dの実エンコードで情報隠しとPNG往復を確認する。旧画面を前提とするソース契約試験は新仕様へ更新する。実画面では貼り付け、注釈編集、トリミング、寸法、ズーム、保存、複数ウィンドウを確認する。対象ウィンドウだけを撮影し、実機入力が必要な場合は事前に知らせる。
