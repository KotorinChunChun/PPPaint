# PPPaint v0.4.0 実装計画・報告

## 設計

現行v0.3.0は元画像を固定背景として持つため、ラスター画像の再選択・移動・重なり順変更ができない。背景キャンバスと画像オブジェクトを分離し、画像・図形・文字・ペンを同じ順序付き編集リストに載せる。保存・コピーは共通レンダラーで合成したPNGとし、元ファイルを変更しない。

- P1: ラスターオブジェクト、重なり順、複数対象の一括変更、精密なヒット判定、線の端点・8方向ハンドルをCoreへ追加し、レンダラーと単体・画像試験で検証する。
- P2: Ctrl+Vとファイルドロップを同じキャンバスへの挿入に変更する。選択枠とハンドル、囲み選択、Shift追加選択、Altで重なりを順に選び直す操作、複数対象の移動・サイズ変更、方向キー、キャンバスのパン、右クリックと重なり順メニューを接続する。
- P3: 架空画像で貼り付け・実ドロップ・端点・辺・再選択・移動・順序・保存結果を実画面で確認し、Releaseビルド・全試験と資料を仕上げる。

「開く」と「新規」は別文書ウィンドウを維持する。「貼り付け」「画像を重ねる」「キャンバスへのドロップ」は既存文書に挿入して選択状態にする。空の未編集ウィンドウへの最初の画像挿入時は、その画像の寸法をキャンバスに採用する。既存キャンバスへ収まらない挿入画像は原寸を維持してキャンバスを必要分だけ拡張する。

矢印・直線は両端を直接ドラッグし、枠形状・画像は四隅と辺中央のハンドルで変更する。Shiftで比率・方向を固定できる。枠図形の内部の空白と画像の透明画素はヒット判定から除き、下の対象へ到達できるようにする。

「範囲」で囲まれた対象を可視化し、範囲内のドラッグでまとめて移動する。選択ツールでもCtrl+ドラッグで背景画像上から囲み選択を開始できる。既存の矩形切り抜き・範囲コピーは維持する。Spaceまたは中央ボタンのドラッグは表示キャンバスのパンとして扱う。

重なり順は常設の大きなレイヤーパネルではなく、選択時の「重なり」メニューと右クリックから変更する。背面の対象はAltクリックと右クリックの対象一覧でも選べる。

## 検証方針

水平・垂直・斜めの端点変更、辺の移動、交差する選択枠、透明画素と枠内部のヒット、複数対象の順序保持とUndo、画像・図形の合成順、PNGの不透明情報隠しを検証する。実画面では1つのウィンドウ内でのCtrl+V、ドロップ位置、再選択、移動、端点と辺、複数選択、順序変更、コピー・保存・Undoを確認する。

## 実施結果

- 着手時: main / 8613d03、作業ツリー変更なし。v0.3.0以前の成果物・資料は保持する。
- P1: 編集可能なラスター画像、順序変更、複数対象の一括変更、端点・8方向ハンドル、枠内部・透明画素を除くヒット判定、GPU画像キャッシュを追加した。Core 222件・Imaging 15件が成功（新規7件を含む）。画面への接続はP2で行う。
- P2: 同一キャンバスへの画像挿入、ドロップ位置への配置、8方向/端点ハンドル、範囲内の対象の可視化と一括移動、Shift追加選択、Altによる重なり再選択、方向キー移動、Space/中央ボタンのパン、重なりメニュー・右クリックを接続した。アプリ内で選択したオブジェクトをコピーした場合は、同一プロセス内の貼り付けで編集可能な型を維持する。外部向けコピーとPNG保存は合成画像にする。
- P2ビルド: Release成功、警告0・エラー0。実操作の結果はP3で追記する。
- P3: UI Automationで貼り付け後のウィンドウ数1、画像の前後変更とPNG画素、選択画像のコピー・20pxずらした再貼付、削除・Undo・保存を確認した。クリップボードの形式取得不整合を修正し、Windowsの変更番号による同一プロセス内コピーの識別を採用した。
- P3補正: 選択済み枠の内部ドラッグ、ペンの連続入力、可視範囲に限定したコピー、最も近いハンドルの選択、矢印の羽のヒット判定を改善した。Core 223件・Imaging 17件の計240件が成功した。
- P3残件: Windows入力デスクトップのアクセス拒否（error=5）のため、実マウス・実キー・外部ドロップと実寸の視認性は未検証。ユーザーへ解除可否を確認し、入力を停止した。詳細は [検証記録](v0.4.0-validation.md) を参照。実装・自動試験の成功を実機検証の完了と混同しない。
- 成果物: ee30cc5から `artifacts/release/v0.4.0/win-x64/` へpublish成功。版・XAML資源・ライセンス通知・SHA-256を確認し、build-receipt.jsonへ記録した。v0.3.0の既存成果物と稼働プロセスは保持した。
