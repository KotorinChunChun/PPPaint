# PPPaint v0.2.5 要求一覧

2026-10-30 ユーザー指示。

- 今後はバージョン末尾を上げ、次版はv0.2.5とする。
- キャンバスの四方をクリック・ドラッグしてキャンバスを縮小したい。
- 矩形に対する操作を、Excelのような修飾キーの複合操作へ広く対応させたい。
- 各操作コマンドの切替キーを割り当て、名前の(A)等のキー部分を下線付きで表示し、ツールチップにも表示する。
- 矩形範囲のぼかしを追加する。
- キーの割当は一般的なツールに合わせ、その根拠を示す。

キャンバス縮小は「画像の解像度を変えず、四辺から切り詰めるトリミング」とユーザー確認済み。

- Ctrlドラッグ複製、Shift比率・移動方向固定、Ctrl中心基準、Ctrl+Shift併用、Alt位置合わせ、Ctrl/Shiftクリック複数選択をすべてv0.2.5に入れる（ユーザー回答）。
- ダイアログのキー操作も入れる。
