# PPPaint v0.2.22 実装計画・報告

## 設計（2026-11-01）

- 貼り付けの既定は重ね合わせ、Ctrl+Shift+Vは５種類の選択。ツールバーは主操作と▼の貼り付け方法を使い分けられるようにする。内部図形・外部ラスタとも重ね合わせで寸法を縮小せず、空の新規文書にもこの条件を適用する。必要な分だけ右・下へ拡張し、１回のUndoで戻す。
- 四隅と四辺を同じ外枠の実描画位置で判定する。クリック開始点からの差分を倍率換算して整数化し、左右／上下両軸を同時に変更できるようにする。外へドラッグした場合は透明な画素余白を追加し、キャンバス背景色で表示する。Ctrlは対角側も同量変更。原点移動・倍率変化のガード、取消、最小サイズと画素上限を保持する。
- 空白クリックは選択を解除する。グループの枠内の空白は押しただけでは動かさず、ドラッグした場合は既存のグループ移動を維持する。キャンバス外の作業余白のクリックでも解除し、ツールバー・リサイズ枠・パン操作とは区別する。
- 「選択を画像に統合」をその他メニューと右クリックへ追加する。選択図形だけを透過のラスタへ描画し、選択内で最前面だった位置に１画像として置き換える。未選択図形、キャンバス寸法／背景、番号を保持し、Undo/Redoで元の図形・重なりを復元する。共通レンダラーを使用し、線幅・矢印先端・マスク・透明画素を切り落とさない。
- 既存のファイル▼／その他▼に加え、重なり・貼り付けなどメニューを持つボタンを点検。１行目のキーは引き続きツールチップだけに表示する。

## フェーズと検証

P1: Core/Imagingの不変条件と回帰試験、UI配線、選択解除、Releaseと全試験、独立レビュー、コミット。

P2: self-contained版を発行。専用画像／設定のUIAと必要な実キー／マウスでCtrl+V/Ctrl+Shift+V、四隅・四辺とCtrl、空白解除、統合・Undoを確認する。画面撮影は対象窓だけ。未保存の旧版を破棄せず最新版を通常デスクトップで起動し、結果を記録・コミットする。

## P1 実施内容・結果

- `ScreenshotPasting.Overlay` にキャンバス寸法を保つ重ね合わせを集約。内部転送と外部ラスタは同じ経路を使い、新規・同寸法・透明画像でも縮小しない。ID・番号・背景・未選択を保持し、大きい軸だけ拡張する。新規文書で明示した連結方向が無視される例外も撤去した。
- 貼り付け主ボタンと隣の▼を分け、Ctrl+V／Ctrl+Shift+Vと同じ操作へ接続。ファイル▼／その他▼／重なり▼も確認。１行目にキーのキャプションを追加しない。
- `ScreenshotCanvasHandle` と `ResizeFromDrag` は８方向、クリックからの差分、対角側のCtrl操作を扱う。既存の４辺Crop APIを保持。`FromBounds` が負の原点を含む余白追加と切り詰めを適用し、原画素・注釈・背景・番号を保持する。サイズ／メモリ上限ではドラッグ方向を保って停止する。
- 四隅の実描画位置に操作枠と斜めカーソルを追加。候補枠はViewport上の非ヒットテスト描画へ分離し、実キャンバスはrelease時に１回だけ変更。Esc・倍率／原点変化では取消。終了時にoverlayも破棄する。
- グループ枠内の空白はクリックで解除、ドラッグでグループ移動。範囲選択内の空白とキャンバス外の作業余白も解除する。独立レビューでCtrl+A後の範囲内空白の漏れを発見して追加対応した。
- `ScreenshotRasterMerge` は元snapshot・選択IDsを保持し、`ScreenshotRasterMergeRenderer` が選択物だけの透過Sceneを共通描画。文字の実描画が宣言Bounds外へ出ても切れないよう、元キャンバス寸法で描いてから実際の非透明画素境界で切り出す。最前面selected位置へ１Imageとして置換し、１回のApplyでUndo/Redoに対応する。
- 統合はCtrl+E、その他▼、右クリックから実行できる。Ctrl+Eは [Adobeの選択レイヤー統合](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/get-started-layers/merge-and-stamp-layers.html) に合わせた。入力欄・gesture中のキー保護とアプリ内エラー表示を維持。

## 検証の境界

今回の実入力は100%表示の専用240×160画像で行った。Core試験の倍率／DPI座標変換は実機の異DPIモニター受入とは別である。右クリック統合は共通handlerへの配線確認で、実マウスでそのメニュー項目を実行する試験は未実施。非連続Zの統合は選択内の最前面へ集約し、間の未選択図形との重なり方が変わる。ぼかし・モザイク・消しゴムの統合効果対象は選択内である。これらはリリース説明へ記載した。
