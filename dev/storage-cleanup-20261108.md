# PPPaint 承認済み容量整理

## 要求

- 前回の第1段階の削除候補約2.33 GiBを削除し、旧配布物・検証記録・設定は残す（2026-11-08ユーザー指定）。

## 実施計画

対象は[前回の候補一覧](storage-cleanup-20261107-candidates.csv)のStageが1-cacheと1-temporary-publishの13フォルダーだけ。第2段階の旧配布物は対象外とする。

リポジトリ内の絶対パス・再解析ポイント・Git追跡ファイル・実行中プロセス・対象内の検証ログや設定の混入を確認してから、PowerShellのLiteralPathで削除する。保持ファイルの一覧とSHA256を削除前後で比較する。LOCALAPPDATA下の設定も保持を確認する。

ソースを変更せず、ビルド・テストは行わない。実行すると削除したキャッシュを再生成してしまうため、検証は保持ファイルの比較、削除対象の不存在、Git差分の確認とする。次回のビルドでは復元・再コンパイルが必要になる。

## 結果

2026-11-08 17:06 JSTに第1段階の13フォルダー・6,806ファイル、2,500,241,050 bytes（2.329 GiB）を削除した。対象は事前の許可リストと一致し、絶対パス・再解析ポイント・Git追跡ファイル・実行中参照を再確認した。検証ログや設定の混入はなかった。

削除前後の保持対象19,918ファイルの一覧・サイズ・SHA256を比較し、変更0・欠落0・追加0。旧配布フォルダー34個、検証結果・画像・ログ、リポジトリ内とLOCALAPPDATA下のPPPaint設定を保持した。GitのHEADも削除操作の前後で不変だった。

証跡はartifacts/storage-cleanup-20261108のbaseline.json、target-files.csv、before.csv、after.csv、verification.json。ファイルの論理容量とボリューム空き容量の観測差はfree-space.jsonで区別した。今回の新しい監査フォルダーと.gitの内部ファイルは保持ファイル比較から除外している。

ソース変更・ビルド・テスト・再publish・push・アプリの強制終了は実施していない。削除後の検証が成功した後で、この実施報告と前回計画への進捗追記だけを更新した。
