# PPPaint v0.2.14 実装計画・報告

## 調査と設計

太さ1のペンも直径1のアンチエイリアス付き円で描いており、整数/小数の座標により複数画素へ色が分散する。通常の編集表示は画面DPI/倍率でベクターを直接描く一方、保存・ぼかし/消しゴム利用時は96dpiのラスタへ描く。読込後の画像は既定の線形補間で拡大縮小され、保存前後で表示の経路が異なる。

太さ1のペンはポインタを含む画像画素（座標のfloor）へ揃える。単独の点は1×1の矩形、連続線は画素中心を結ぶアンチエイリアスなしの幅1のパスとして描く。線の太さ2以上と他の図形の滑らかな描画は保持する。コピー/範囲クリップの描画境界も画素範囲へ合わせる。

編集表示はプレビュー/ドラッグを含め、保存と同じ96dpiの合成画像から行う。表示時は最近傍補間で画素を維持する。選択枠・ハンドル・ポインタは従来の別Canvasで描く。画面倍率は画像の画素数を変えない。マウス移動や選択変更だけで全面合成し直さないよう、既存の描画キャッシュで同一画像の合成結果を再利用し、変更/デバイス再作成/終了で更新・破棄する。

## 計画

- P1: 画素単位の再現試験を先に実施。ペン描画・境界・表示補間・合成結果再利用を修正し、PNG往復/透明背景/小数座標/画像端/連続線/クリップ/Undo/Redo/倍率とDPIの回帰を検証。Releaseビルドと全テストを実施しコミット。
- P2: 隔離した実アプリで架空の1画素画像を開き、ペン太さ/倍率/PNG保存・再読込のUIAと全RGBAを確認。配布用ビルドを作成し、旧版の作業を保持して更新版を起動する。実入力・実画面撮影の可否を記録してコミット。

## P1 実施結果

修正前の再現試験6件が失敗。座標8,9では4画素へ分散し、8.5,9.5では1画素でも#FFFF7F7Fへ薄くなることを確認した。PNGエンコード前から色が分散しており、保存時のデータ欠落とは区別した。

太さ1のペンは画素へ揃えた矩形/パスへ変更し、スクエア端点と丸い接続で連続線を維持。半透明の同一点・往復でも同一ストロークの色を重ね塗りしない。DrawPixelPenだけでアンチエイリアスを切り替え、終了時に必ず元へ戻す。範囲コピー/削除用のDrawingBoundsを実際の画素境界へ合わせた。

表示経路は選択・ドラフトを含め96dpi合成へ統一した。最近傍補間の共通メソッドを使い、選択枠などは別Canvasのまま。ScreenshotRenderCacheに合成結果の所有と再利用を追加し、画像内容の変更だけで作り直す。

Releaseビルド警告0・エラー0。Core256/Imaging48、全304件成功、失敗/スキップ0。追加15件では点6座標×白/透明、PNG全RGBA往復と再ラスタ化、5方向の連続線、半透明の重複/往復、範囲コピー/削除/移動/Undo/Redo、4倍率×4DPIの表示一致/にじみなし、キャッシュ再利用と更新を確認した。連続性判定は走査順の隣接比較では負傾斜を誤判定したため、8近傍の到達性判定へ修正した。

## P2 配布版と最終起動

P1コミット9b2dea9b1c07ffe75935c57246ba9641088f1722からRelease x64 self-containedをpublish。配布資源とライセンス通知、EXE/DLLの版・SHA256を確認した。

配布版を隔離設定で起動し、架空の1画素PNGをTest-EditorV0214Pixels.ps1で検証。太さ1・4倍率の設定、PNG保存/再読込/別ウィンドウでの再保存、元画像との全RGBA一致に成功し、検証用2ウィンドウを通常終了した。GetForegroundWindowは0のため、実マウス/キー入力と画面撮影は行っていない。

旧v0.2.13 PID7660は実行先/セッション/管理パイプPID/版を照合し、未保存や編集中の操作がある場合は拒否される既存stopがacceptedとなり通常終了した。旧v0.2.11の作業は操作せず保持。新v0.2.14は通常設定で起動し、PID21420「無題 - PPPaint - v0.2.14」、IsOffscreen=false、配布版の実行先を確認した。ペン太さ1・100%表示で起動したまま残した。未保存作業は破棄していない。証跡は配布フォルダーのbuild-receipt.json / old-endpoint-stop.json / final-startup.json、詳細はv0.2.14-validation.md。
