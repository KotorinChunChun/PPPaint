# ChunPaint v0.2.0 検証計画・結果記録

作成日: 2026-09-12。対象要求は `dev/v0.2.0-req.md` の R01〜R17。
この文書の初版はソースと過去の監査記録の照合から作成した。実装、テストコードの存在、実行成功、実機成功を区別する。実行ログや画面記録がない項目は合格にしない。

## 記録方法

- 自動検証: 実行日時、コマンド、合格/失敗/スキップ数、ログ保存先を記載する。
- 手動検証: OS、表示倍率、入力機器、操作、期待値、観測値、画面/動画のパスを記載する。
- デバイスや資格情報が必要な検証は「環境待ち」とし、コード実装完了と混同しない。
- テスト中に作る画像・設定・出力先は専用の試験用データとする。印刷確定、壁紙変更、外部AI送信、署名・実インストールは明示した試験手順で扱う。

### 履歴・設定の最終確認

- 新規タブで40ストローク、40回Undoで空白へ復帰、40回Redoで再描画。描画領域310×260pxを比較し、最初の描画・Redo後・別タブから復帰後の差分画素は0。証跡は `history-40-drawn.png`、`history-40-undone.png`、`history-40-redone.png`、`history-tab-restored.png`。
- 線幅を11へ変更し、5秒の設定保存後に同じ試験プロファイルで別インスタンスを起動。UIのRangeValueが11であることと、稼働中インスタンスのバックアップに復元ダイアログを出さないことを確認した。証跡は `preferences-relaunch.json`。
- サブエージェントの別画面取得経路が337秒応答しなかったため、入力0件の状態で中断。親が既存のUI Automation経路で上記試験を実施した。アプリの障害としては扱わない。
- デスクトップ方式の録画 `9978f6469a244432904f2a52e626ccea` はcompleted/decoded=true。開始・操作中・終了フレームに対象アプリを目視し、確認シナリオの証拠としてpass登録。動画は `dev/test-videos/2026年09月12日_15時18分35秒_ChunPaint 復元とWebP保存の修正確認のテスト風景_9978f6.mp4`。Git・公開物には含めない。
- 大画像でのGPU/CPU実メモリ上限、保存/破棄と復元の競合を網羅する障害注入、実コピー・印刷との全描画一致、各DPI/実ペン等は引き続き未確認。成功したシナリオを全受入の合格へ拡張しない。
