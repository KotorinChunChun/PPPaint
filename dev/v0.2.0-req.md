# PPPaint v0.2.0 要求一覧

作成日: 2026-09-12。ユーザーは提案全項目の実装とサブエージェント活用を指示し、v0.2.0への集約を承認した。

## 未完了

- R14 全UIアイコンの統一。既存台帳の92機能・状態と配置を追跡し、実寸で検証する。
- R16 DPI・キーボード・読み上げ・高コントラスト、印刷・共有・壁紙・インストール更新削除・異常系の残件を検証する。
- R17 ブラシ描画見本との差分評価、既存要求・タスクの状態整合と利用者資料の更新。

R14は92種の素材生成・接続コードが反映済みで、実アプリ全配置の実寸確認が未完了。R16は環境依存の受入確認、R17は描画見本との差分評価が残る。

## 実装済（コード反映済み）

- R01 自動保存・異常終了からの復元。元ファイルを上書きせず、複数起動・保存中の追加編集を考慮する。
- R02 ブラシ・線幅・色・表示設定の永続化と初期値復帰。
- R03 レイヤーのロック・不透明度。画面、保存、コピー、結合、印刷、Undoの結果を一致させる。
- R04 履歴のメモリ上限と変更領域の共有。長いUndo/Redoの順序を保持する。
- R05 高品質リサイズ。ドット絵向け最近傍と滑らかな補間を選べる。
- R06 選択範囲へのモザイク・ぼかし・不透明な黒塗り、プレビューと取消。
- R07 明るさ・コントラスト・彩度の調整、プレビューと取消。
- R08 WebP入出力、書き出し画質・透過・容量確認。
- R09 筆圧による線幅・濃さ、手ぶれ補正。マウスの従来動作を保持する。
- R10 背景除去の許容差、残す／消す手直し、境界調整。
- R11 複数画像のタブ編集。保存先・Undo・ズーム・未保存確認を文書別に保持する。
- R12 複数画像の一括変換。進捗・取消・ファイル別結果を表示する。
- R13 生成消去・AI画像編集。接続設定、送信範囲と同意、資格情報保護、タイムアウト、障害説明、利用量制御、結果確認とUndoを提供する。
- R15 MSIX・署名・自動更新の配布経路を整備し、既存ユーザー単位インストールを維持する。

この区分は機能コードの反映を表し、すべての実機受入や外部サービス検証の合格を表さない。Core 215件・Imaging 12件が成功。自動復元、WebPの容量一致と再読込、タブ、ぼかしUndo、レイヤーロック・不透明度を実UIで確認した。要求ごとの検証範囲と未確認事項は実装報告および dev/v0.2.0-validation.md を参照する。R13の実API接続、R15の正式署名・公開配布・クリーン環境確認は環境待ち。

## 追加要求（2026-09-12、提案全項目の実装指示）

- R18 選択範囲の強化: 色による自動選択、楕円、追加・差し引き、境界ぼかし。
- R19 レイヤーマスク: 元画像を保持して隠す/戻す、ブラシによる編集。
- R20 配置・整列・ガイド: 中央・端・等間隔、ガイド吸着、位置と寸法の数値入力。
- R21 グラデーション: 線形・放射状・透明への変化。
- R22 レイヤーの描画モードとグループ: 乗算・スクリーン・オーバーレイ、整理と一括操作。
- R23 トリミング強化: 比率固定、出力寸法指定、傾き補正。
- R24 操作履歴パネルと加工前後比較。
- R25 写真補正: ヒストグラム、レベル、トーンカーブ、ホワイトバランス。
- R26 コピースタンプと修復ブラシ。
- R27 調整レイヤー: 補正設定を保持し、保存・再読込後も編集。

上記はユーザーの「提案機能を全部実装して」による追加要求。既存v0.2.0へ統合し、旧資料の移動・公開は行わない。
