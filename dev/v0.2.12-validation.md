# v0.2.12 検証記録

## 再現と修正

白いキャンバスに線・丸・四角・矢印を描いてぼかしを加えた修正前テストが失敗。範囲外(0,0)のRGBAが#FFFFFFFFから#00000000へ変わり、矩形外が透明に置き換わることを確認した。修正前画像はartifacts/qa-v0.2.12/before-fix。

マスクなしのDrawImage合成をCanvasComposite.BoundedCopyへ変更し、非限定のCopyを除いた。マスクありは既存の幾何だけのクリアとSourceOverを維持した。修正後画像はartifacts/qa-v0.2.12/after-fix。矩形外の図形と背景が維持されることをオフスクリーン描画でも確認した。実画面撮影とは区別する。

## 自動試験

.NET SDK10.0.401 / Windows x64。Release警告0・エラー0、Core256/Imaging33の全289件成功、失敗・スキップ0。

- 白/透明/半透明×画像の有無×ぼかし/モザイク×マスクの有無、24通りで、対象外の全画素のRGBAが不変。
- 範囲内に実際の効果があること、クリップと切取穴、既存の図形の編集情報/ID保持。
- 複数ぼかしを加えても、それ以前のぼかしや外の画像が残ること、後から重ねた図形の順序。
- 効果の移動/削除/Undo/Redoで元画素を維持し、効果を除去すると元の画像へ戻ること。Redoの追加確認後、効果保持の4試験を再実行して成功。
- PNG往復の全画素一致と、既存の配置・背景・クリップ・保存形式/競合などの回帰。
