# v0.2.38 バケツと右ボタン用の作図色

- 旧版のバケツは、コミット `019312b` のエディター再構成でツール一覧から外れた。現行のエディターにバケツを追加し、合成後の画素を上下左右にたどって一致する範囲だけを塗る。塗った画素を透明部分付きの画像として重ね、既存の図形や効果を編集可能なまま保持する。1回の塗りつぶしを1件の取り消し履歴に記録する。
- パレット右クリックとスポイト右ボタンで色2を更新する。色2は白を初期値とし、色の指定ボタンに表示して、設定ファイルに保存する。作図や採色を開始したボタンを操作の確定まで使う。
- 選択・移動と矩形範囲の右クリックメニュー、パレットのダブルクリック編集、キャンバスの背景設定を維持する。
- Windows x64のReleaseビルドと修正版の起動を確認する。

## 確認結果

- Windows x64のReleaseビルドに成功。通常の設定先を引き継いでv0.2.38を起動し、ウィンドウの表示と準備完了を確認した。未保存の文書を持つv0.2.37のウィンドウは保持した。
- ショートカット定義のJSONを読み込めること、キーの重複がないこと、差分に空白エラーがないことを確認した。機能テストは省略した。
