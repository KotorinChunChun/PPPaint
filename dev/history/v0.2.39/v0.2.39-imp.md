# v0.2.39 オブジェクト一覧とハンドル表示

- 開閉できるオブジェクト一覧をキャンバスの右側に追加し、上から前面順に表示する。一覧の選択はキャンバスと同期し、重なっていても対象を名前と順番で特定できるようにする。
- 全ハンドル表示を追加する。通常の選択ハンドルは青、その他は灰色とする。選択・移動ツールでは灰色のハンドルからも個別選択と編集を始められるようにし、ハンドルの位置と当たり判定をそろえる。
- 一覧の移動ボタンと項目の右クリックで、最前面・1つ前・1つ後ろ・最背面への移動を行う。キャンバスの右クリックメニューと既存の並べ替え処理を共有する。選択と表示切替は画像や履歴を変更せず、重なり順の変更は元に戻せる。
- Windows x64のReleaseビルドと修正版の起動を確認する。

## 確認結果

- Windows x64のReleaseビルドと、v0.2.39の画面表示・準備完了を確認した。未保存のv0.2.38を開いたまま、通常の作図設定を隔離先へコピーしてv0.2.39を起動した。
- 差分の空白検査を実施した。機能テストは省略した。
