# 公開前監査と旧素材の除外

対象: PPPaint 0.2.0。実施日: 2026-10-29。依頼は公開適性の点検後のpublic化、追加指示は旧素材の削除許可。機能テスト・ビルドは実施しない。

## 点検結果

- 元の全refsに到達する86コミット、1,713 blob、約25 MBを走査した。固定の秘密鍵、PAT、APIキー、JWT等のパターン、実資格値、個人メール、LAN IP、個人ユーザーパスは検出しなかった。
- 高エントロピー文字列と資格付きURLの候補は、1画素PNGとexample.comを用いるテストデータであり、実資格情報ではなかった。作者情報はCodex/codex@localhostのみ。
- 現行966ファイル、PNG717枚、履歴資産708 blobを棚卸しし、大画像68枚を一覧で目視、3枚を原寸確認した。顔写真・顧客画像・認証キー等の写り込みは見つからなかった。
- 旧コミットにはMicrosoft Paint画面から切り出した4アイコンが残っていた。現行製品では独自素材へ置換済みでも、履歴ごとの公開には不適切と判断した。
- 依存ライブラリ実体、証明書、利用者の画像プロジェクト、DB、モデル、動画、ログは追跡されていなかった。現行カーソルDLLは独自生成のリソース専用PEで、生成スクリプトと出典台帳がある。

## 対処

- 旧アイコン4点、Microsoft Paint観察画像12点、旧素材の写り込みがあり得る開発画面の生証跡と索引を公開する全履歴から除外する。元のローカルファイルはGit対象外で保管する。
- 旧素材の正本が残る旧GitHubリポジトリを非公開の保管用へ改名し、同じPPPaintのURLに除去済みの開発履歴を持つ公開用リポジトリを用意する。旧Gitオブジェクトを新リポジトリへ送らない。
- 今後の撮影先を版別logsへ統一し、撮影索引のない公開cloneでも通常の品質ゲートが索引の不足だけで失敗しないようにする。明示的な撮影要求時は索引を必須とする。
- 秘密情報・証明書・旧素材・生証跡を.gitignoreで除外する。MITの元著作権表示を保持してPPPaintの表示も追記する。
- 親KotorinToysのGitリンクを公開用の確定コミットへ更新する。製品の配布状態は未公開のままとし、配布リリースや実インストールは行わない。

Microsoftの確認資料: [著作物の利用条件](https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions)。スクリーンショットの部分利用・製品UIへの組込みに関する条件を確認し、問題の素材を公開対象へ含めない方針を採用した。

## 限界

独自パターンによる静的監査であり、未知形式の秘密情報を数学的に不存在と保証するものではない。画像は一覧中心の目視であり、機能・操作品質の合格を意味しない。監査の生ログ、画像一覧、旧ファイルは版別logsまたは非公開の旧履歴に保持し公開しない。

## 保存・公開結果

旧リポジトリはPPPaint-private-history-20261029として非公開を維持。公開用PPPaintは旧リポジトリとは異なる新しいGitHubリポジトリに作成した。除去済み履歴は87コミット、現在843ファイルで、旧画像・生証跡のパスは全refsに存在せず、git fsckも成功した。現在のソースtreeは除外処理後の元treeと完全に同一。ローカルの元.gitも版別logs内のoriginal-private.gitへ保管し、作業フォルダーの.gitを除去済み履歴へ切り替えた。これにより旧コミットが同じGitHubリポジトリ内に残る状態を避ける。

2026-10-29、KotorinChunChun/PPPaintの可視性をPUBLICへ変更した。匿名REST APIでprivate=false、READMEのHTTP 200、ソースZIP843ファイル・除外対象0、資格情報ヘルパーを無効化したgit ls-remoteでmain取得を確認した。旧素材の導入コミットは公開用リポジトリでは取得できず、PPPaint-private-history-20261029はPRIVATEを維持している。公開操作時のGit転送は可視性の反映直後に一度認証を要求したが、反映後の匿名再取得は成功した。
