# v0.2.40 矢印の連続作図と専用カーソル

- 矢印の確定時は、ペンと同じ経路でツールを維持し、直前の矢印のハンドルを選択しない状態に戻す。選択・移動ツールから確定済みの矢印を引き続き編集できる。
- バケツと矢印は、既存のカーソル生成スクリプトで専用の図柄と描画位置を示す十字を作る。Windowsリソースへ登録し、描画領域上でツールに応じて切り替える。
- オブジェクト一覧でドラッグした項目を挿入線の位置へ移す。複数の選択項目は相対順を保持し、ドロップ時の変更を1件のUndoとして記録する。公開前確認でコントロール標準のドラッグが確定しなかったため、一覧内のポインター操作として実装する。
- 選択・移動ツールで囲った場合は、囲いに含まれるオブジェクトを選ぶ。選択した複数のオブジェクトをまとめてドラッグできる。合成画素の切り離しは矩形範囲ツールから行う。
- Windows x64のReleaseビルド、同梱したカーソルリソースの読み込み、修正版の起動を確認する。

## 確認結果

- Windows x64のReleaseビルドとv0.2.40の起動を確認した。未保存のv0.2.39を保持し、作図設定をコピーした別プロファイルで起動した。
- 2種類のカーソルがそれぞれ32・48・64 pxでWindowsから読み込めることと、十字の中心にホットスポットがあることを確認した。ビルド出力に含めたDLLは生成した資源と同一だった。48 pxのマスク行幅もWin32の形式に合わせた。
- 差分の空白検査を行った。実画面での作図・ドラッグ操作のテストは省略した。
