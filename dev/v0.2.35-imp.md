# PPPaint v0.2.35 実装計画・報告

## 前提

- v0.2.34（HEAD `e5d531b`）、作業ツリー変更なしから開始。ユーザーの確認回答は要求定義に追記済み。
- 機能追加を一つのv0.2.35として4フェーズで進める。各段階でビルド・関連試験と結果記録を行い、コミットする。
- 既存画像・作業窓・配布物・過去版の記録を保持する。作者・実行者はリポジトリのKotorinChunChun。

## P1 設計

- ペン描画中のdraftの矩形枠だけを抑止する。選択・移動時の編集ハンドルや●は維持する。
- V/Mで囲った領域をドラッグすると、見えている合成結果を整数画素の画像に切り離す。残りは元の画像／図形のマスクで維持し、移動・Ctrl複製・Shift方向固定・Alt吸着、Undo/Redo、Esc取消に対応する。文書の確定はマウスを離したときだけとし、取消で履歴を変えない。
- ぼかし／モザイクの参照画素が切断で変わり領域外も変化しないよう、範囲移動時は既存の効果結果を画像として固定する。その他の範囲外図形は編集可能なまま維持する。
- スポイトは押下で開始し、キャプチャ中にプレビュー色・色番号を表示、解放地点で新規作図色へ採用する。Esc・キャプチャ喪失・外側での解放は取消。選択図形の色は変えない。

## P2 設計

- 四角／円／矢印／番号に独立した▼メニューを設け、選択中なら対象を変更、未選択なら次の作図用設定を変更する。新規作図設定と選択値を混同しない。
- 四角は輪郭／不透明塗りつぶし。情報隠しの単独ボタンは統合する。円も輪郭／塗りつぶし。
- 矢印は線・両端・ブロック・陰影付き立体。各種類で塗りつぶし有無を選ぶ。番号は丸・四角・囲みなしと塗りつぶし有無。
- モデル、当たり判定、表示、範囲コピー、保存の全てへ同じスタイルを反映する。作図用スタイルは再起動後も保持する。

## P3 設計・参照

- Office系のサイズ変更ハンドルと形状調整点を参考に、吹き出しに本文の8方向、尾の先端、付け根2点を表示する。本文の編集と尾の形状編集を分離し、移動・サイズ変更・回転／反転で追従する。
- 上部の文字欄はツール選択時と作成済み吹き出しの選択時の両方で表示する。ダブルクリックで編集欄にフォーカスし、複数行入力・文字サイズ変更に合わせて本文枠を拡張する。
- Microsoftの図形の塗り・輪郭・調整点と「文字に合わせて図形をリサイズ」、Bluebeamの吹き出し本文とリーダー端点の独立操作を参考とする。完全互換や任意多角形の編集を目標にはしない。
- 参照: https://support.microsoft.com/en-us/powerpoint/add-shapes
- 参照: https://support.microsoft.com/en-us/powerpoint/training/set-text-direction-and-position-in-a-shape-or-text-box-in-powerpoint

## 結果

### P1

- ペンのdraft枠を非表示とした。範囲を囲った後のドラッグは、選択範囲の合成結果を画像にし、残りのベクターとラスターをマスクで維持する非破壊のドラッグ計画へ変更した。確定時だけ1回Applyし、Ctrl複製／整数移動／Shift方向固定／Alt吸着、Undo/Redoと取消を既存入力経路へ接続した。
- 既存のぼかし・モザイクは合成結果をSourceCopyする画像へ固定し、元画素を切ったことで範囲外の効果が変わらないようにした。その他の範囲外図形は編集可能なまま維持する。
- 新規GPU試験で、離れた場所にマスクを追加するだけでもペンの半透明な縁が薄くなる既存の外周クリップを検出した。外周の幾何を画素境界より十分外側へ拡張し、必要なClipBoundsとCutoutsだけを適用して解決。白／透明背景で範囲外RGBAが全画素一致した。
- スポイトは押下時に1枚の合成スナップショットを取得し、キャプチャ中に1pxずつ色を読み、カーソル横へ色見本とHEXを表示する。離した地点で新規作図色へ採用し、選択図形は変更しない。Esc・キャプチャ喪失・範囲外解放は取消とする。
- Release警告0／エラー0、Core245＋Imaging104＝349試験成功。証跡は `artifacts/qa-v0.2.35/p1-fixed-tests.log`。初回の外周クリップ不一致は `p1-tests.log` に保持した。入力の実マウス確認は後段で扱う。

### P2

- 四角・円・矢印・番号を主ボタン＋▼にした。四角の塗りつぶしを不透明な情報隠しとして統合し、K／Alt+Kは塗りつぶし四角の呼び出しとして保持した。情報隠しの単独ボタンは表示しない。
- 矢印4種類と塗りつぶし、円の塗りつぶし、番号の丸／四角／囲みなし・塗りつぶしをモデル・描画・当たり判定へ反映した。スタイルはコピー、複製、Undo/Redoでも維持する。
- 作図用スタイルと選択図形の値を分離し、作図用の変更だけを設定へ保存する。複数窓の数値設定と独立してマージし、明示的な「設定を取得」では図形スタイルも取得する。
- Release警告0／エラー0、Core248＋Imaging113＝361試験成功（`p2-fixed-tests.log`）。PNGのalphaと画素位置を確認し、アンチエイリアスの半透明な縁はstraight/premultiplied変換の丸め1階調までを許容する。完全不透明画素とalphaは一致する。
- 一時publish版で四角・円の塗り、矢印4種類と塗り、番号3種類、囲みなし時の塗り無効化、単独情報隠しボタンの廃止をUIA確認した（`artifacts/qa-v0.2.35/p2-menus/shape-menus.json`、PID17824は終了済み）。初期の吹き出しツールを選択した際の文字欄は表示されており、作成後の選択時の保証・専用の上部配置・自動拡張はP3で実施する。

### P3

- 吹き出しは本文枠の8ハンドルに加え、黄色い尾の先端・付け根2点を独立表示する。付け根は本文の辺に沿って移動し、別の辺へも移せる。尾と本文は幾何の和集合で描き、尾を反対側へ向けても本文に穴を作らない。
- 付け根の比率をモデルに保持し、サイズ変更・移動・回転・反転・クリップ・コピーへ追従させた。ヒット判定も実際の尾の三角形を使う。
- 文字欄を上部の専用行へ移し、幅をウィンドウへ追従させ、複数行入力を可能にした。実フォントのCanvasTextLayoutで文字量を測り、作成時・文字編集時・文字サイズ変更時に本文枠を拡張する。尾の先端を保持し、下／右を向く尾では可能な範囲で本文を上／左へ広げる。
- Release警告0／エラー0、Core252＋Imaging116＝368試験成功（`artifacts/qa-v0.2.35/p3-tests.log`）。3調整点、回転・反転時の付け根、和集合、複数行の本文拡張を回帰試験で確認した。
- 一時publish版で図形メニューと上部の吹き出し文字欄をUIA再確認した（`p3-menus/shape-menus.json`、PID37672は終了済み）。作成・ドラッグなどの実入力確認はP4で扱う。
