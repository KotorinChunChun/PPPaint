# PPPaint v0.2.5

- バージョンは今後v0.2.5、v0.2.6…と末尾だけを上げる。
- キャンバスの左右上下の境界帯を内側へドラッグすると、解像度を変えずに切り詰める。残す範囲と寸法をプレビューし、離すと確定する。Escで取消、Undoで復元できる。
- 矩形ぼかしを追加した。位置・寸法・強さ・重なり順を保持し、下の画像・図形に作用する。コピーとPNG保存にも反映する。
- ツール名に下線付きのキーを表示し、ツールチップへもキーを表示する。文字・数値の入力中は単独キーで切り替えない。
- 主要コマンドのCtrlキーと、補助操作のAltアクセスキーも表示する。

- Ctrl/Shiftクリックで選択の追加・解除、Ctrlを押したままドラッグで選択した図形・画像を複製する。
- Shiftで縦横の移動方向・サイズ変更の比率を固定し、Ctrlで中心基準、Ctrl+Shiftで両方を適用する。新しく矩形を描くときのShiftは正方形になる。
- Altでキャンバスと他の図形の辺・中心へ吸着し、ガイドを表示する。重なった対象は右クリックの「選択する対象」で選び直す。
- ダイアログはTab/Shift+Tab、Enter/Esc、下線キーのAltアクセスに対応する。確定Alt+S、副操作Alt+D、取消Alt+C。未保存破棄・上書きの確認は取消が既定。
- ファイル画面はフォルダーAlt+L、名前Alt+N、上位Alt+Up、一覧のEnterで移動/確定。寸法画面は幅Alt+W、高さAlt+H、比率Alt+R。

[キー割当と公式資料の根拠](keyboard-shortcuts.md)を参照。

旧版で作業中の場合は、画像を保存して旧版を閉じてから新しい実行ファイルを起動する。

自動試験とUI Automationによるキー情報・境界帯・ダイアログを検証する。結果は[検証記録](../dev/v0.2.5-validation.md)を参照。実機の前面化ができなかったため、実ドラッグ・実キー・実寸の見やすさは未確認。
