# Windows 11 Paint 実機観察仕様

## 1. 目的と境界

PPPaint の互換 UI と操作仕様を、Windows 11 Paint の実機操作から記録する。これはクリーンルーム観察であり、Paint のコード、DLL、アイコン、画像、内部データは利用しない。

## 2. 観察環境

| 項目 | 値 |
|---|---|
| 観察日 | 2026-08-29 |
| Windows build | 26100 |
| Paint | 11.2605.81.0 x64 |
| UI 言語 | 日本語 |
| DPI | 120（125%） |
| 初期画像 | 1152 × 648 px |
| 初期ズーム | 100% |

## 3. 画面構造

- 上部はタイトル領域、メニュー、リボン状ツールバーの順。
- ツールバーには選択、画像操作、ツール、ブラシ、図形、色、レイヤー、生成系機能が並ぶ。
- 中央は灰色の作業領域に白いキャンバス。
- 下部ステータスバーに位置・選択寸法・画像寸法・ズームを表示。
- レイヤーを開くと右側にサイドバーが現れる。

## 4. ファイルメニュー

- 新規 `Ctrl+N`
- 開く `Ctrl+O`
- キャンバスにインポート（サブメニュー）
- 最近使ったもの（サブメニュー）
- 保存 `Ctrl+S`
- 名前を付けて保存（PNG、JPEG、BMP、GIF、その他の形式）
- プロジェクトとして保存 `Ctrl+Shift+S`
- 印刷（サブメニュー）
- 共有
- デスクトップの背景として設定
- 画像のプロパティ `Ctrl+E`
- 終了

画像のプロパティには最終保存日時、ディスク上のサイズ、解像度（観察時 120 DPI）、単位（インチ・cm・ピクセル）、幅、高さ、既定値、OK、キャンセルがある。幅と高さは 1～99999。

## 5. 編集・表示メニュー

編集には切り取り、コピー、貼り付け、表示レイヤーをコピー `Ctrl+Shift+C` がある。対象がない操作は無効になる。

表示にはズーム、ルーラー `Ctrl+R`、グリッド `Ctrl+G`、ステータスバー、ツールバーを常に表示、ツールバーの自動非表示、全画面 `F11`、サムネイルがある。

## 6. 画像操作

- 選択: 矩形、自由選択、すべて選択、選択範囲を反転、透明な選択、削除。
- 回転: 右 90°、左 90°、180°、カスタム回転。
- 反転: 垂直、水平。
- サイズ変更と傾斜: パーセント／ピクセル、水平／垂直、縦横比ロック、水平／垂直の傾斜角、OK、キャンセル。
- 左 90°回転では画像寸法が 1152×648 から 648×1152 に交換され、1 回の Undo で全体が戻った。

## 7. ツールとブラシ

確認した主要ツールは鉛筆、塗りつぶし、テキスト、消しゴム、スポイト、拡大鏡。鉛筆では線幅と不透明度を変更できる。1 回のドラッグで描いたストロークは 1 回の Undo 単位。

ブラシ一覧:

- ブラシ
- カリグラフィ ブラシ
- カリグラフィ ペン
- エアブラシ
- 油彩ブラシ
- クレヨン
- マーカー
- 鉛筆（標準）
- 水彩

## 8. 図形

図形一覧:

- 線、曲線、楕円、四角形、角丸四角形、多角形
- 三角形、直角三角形、ひし形、五角形、六角形
- 右・左・上・下矢印
- 4・5・6 ポイントの星
- 角丸・楕円・雲形の吹き出し
- ハート、稲妻

図形を選ぶと輪郭、塗り、線幅が有効になる。輪郭と塗りには「なし」「単色」「クレヨン」「マーカー」「油彩」「鉛筆（標準）」「水彩」がある。配置直後は 8 個のリサイズハンドルと回転ハンドルを持つ浮動オブジェクトになる。

## 9. テキスト

テキスト選択時はキャンバス上部にフローティングツールバーが出る。確認項目はフォント（既定 Calibri）、サイズ（既定 11）、太字、斜体、下線、取り消し線、左・中央・右揃え、背景の塗り。キャンバスをクリックすると変形可能なテキストオブジェクトが作られ、8 個のリサイズハンドルと回転ハンドルが表示される。

## 10. 選択

矩形選択はドラッグ後に 8 個のリサイズハンドルと回転ハンドルを持つ。ステータスバーに位置と寸法を表示し、下部の小型バーから生成消去と背景除去を呼び出せる。

キーボード操作の案内:

- `Ctrl+Space`: 適用
- `Esc`: キャンセル
- 方向キー: 移動
- `Tab` / `Shift+Tab`: ハンドル間移動

選択中の右クリックメニューには、切り取り、コピー、貼り付け、表示レイヤーをコピー、トリミング、すべて選択、選択範囲を反転、削除、背景除去、生成消去、回転、反転、サイズ変更、色の反転がある。

## 11. 色

色1の初期値は黒、色2は白。パレットを左クリックすると色1、右クリックすると色2が変わる。

観察した 20 色は、黒、灰色、濃い赤、赤、オレンジ、黄、緑、ターコイズ、藍、紫、白、薄い灰色、茶、ローズ、金、薄い黄、黄緑、薄いターコイズ、青灰、ラベンダー。

## 12. レイヤー

- 右サイドバーの `+` で透明レイヤーを最上段に追加して選択する。
- 透明部分はチェッカーボードのサムネイルで示す。
- 選択レイヤーは紫色の枠で示す。
- 各レイヤーに表示／非表示の目アイコンがある。
- 背景は通常レイヤーと別項目として表示される。

レイヤーの右クリックメニュー:

- 非表示 `Ctrl+H`
- 複製
- 下のレイヤーと結合
- 上へ移動 `Ctrl+Shift+PageUp`
- 下へ移動 `Ctrl+Shift+PageDown`
- 削除 `Ctrl+Shift+Delete`

最上段では「上へ移動」が無効になる。

## 13. Undo / Redo

- 1 回の連続ドラッグは 1 履歴単位。
- キャンバス全体の 90°回転も 1 履歴単位。
- UI の有効／無効状態は履歴の有無に追従する。
