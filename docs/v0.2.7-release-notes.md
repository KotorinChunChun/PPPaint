# PPPaint v0.2.7

- Ctrl+Aでキャンバス全体を矩形範囲として選択。Ctrl+Cは常にキャンバスと同じ寸法の画像をコピーする。
- Ctrl+Xで範囲をコピーして削除。範囲がないときは選択対象を切り取る。Undoで戻せる。
- 同一アプリ内の直前のコピーは、背景・画像・図形を分離して貼り付ける。貼り付け後も図形を再編集でき、黒背景になる問題を修正した。外部向けコピー・保存は合成したラスタ画像になる。
- 左下の背景色でRGB/アルファと透明を変更。既定は白（255,255,255）。読み込んだ画像の不透明な画素自体は塗り替えない。
- キャンバスの四辺をCtrl+ドラッグすると中心を固定し、反対辺も同量切り詰める。拡大・再サンプリングはしない。
- Ctrl+ホイールで表示倍率を変更。通常の右下の倍率バーも使える。
- 番号の開始値を変更して再開できる。押したままドラッグで配置をプレビューし、離して確定する。
- 文字・吹き出し・透かしのダブルクリックで文字入力欄へフォーカスする。
- 標準の移動・リサイズ・文字カーソルを使い分け、ポインタ右下にも操作名を表示する。操作目印と選択枠は出力に含まれない。

1行目のキーはツールチップのみ。既存の保存・バックアップ・修飾キー操作も維持する。

[キー一覧と根拠](keyboard-shortcuts.md)、[検証結果と実入力の制限](../dev/v0.2.7-validation.md)を参照。
