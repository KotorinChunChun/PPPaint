# v0.2.34 変更内容

- ペンの描画予定位置へ、色と太さを合わせた●を追従表示します。鉛筆カーソルは維持します。1pxでは実際に描かれる1画素を示します。
- 表示倍率やDPIを変えた場合も実描画と同じ画素を示し、キャンバス外へは出しません。ドラッグ中は描線のプレビューを使い、同じ縁を二重に描きません。
- 全ツールの既定太さは3です。今回の設定引継ぎに限り、記憶済みの太さも3へそろえます。色や文字サイズは保持し、その後の太さの変更もツールごとに再起動後まで保持します。
- プレビューの●は文書・Undo・画像コピー・保存へ含めません。

詳細は [実装・検証報告](../dev/v0.2.34-imp.md)、操作は [利用ガイド](user-guide.md) を参照してください。
