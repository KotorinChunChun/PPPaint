# v0.2.31 変更内容

- 図形だけの移動・複製で、Altによる小数座標への位置合わせが丸めでずれる問題を修正しました。画像を含む選択と矩形範囲は整数画素の移動を維持します。
- 文字・吹き出し・透かし・番号の編集で、Ctrl+S後の追加入力をUndoすると保存時の状態へ戻れるようにしました。
- キー定義JSONのコピー・貼り付け・切り抜きの説明を現行動作に合わせ、Ctrl+Shift+VとCtrl+Eを追記しました。開発資料の旧機能削除範囲の説明も修正しました。

検証範囲と結果は [実装・検証報告](../dev/v0.2.31-imp.md)、操作は [使い方](user-guide.md) と [キー一覧](keyboard-shortcuts.md) を参照してください。
