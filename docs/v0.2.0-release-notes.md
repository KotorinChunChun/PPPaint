# PPPaint v0.2.0 リリースノート

2026-09-12。Windows 11 x64向けのself-contained非MSIX構成です。v0.2.0要求R01～R17を対象に機能追加と検証基盤の整備を行いました。実装された経路と、外部設備が必要な受入確認を分けて記録します。

## 追加機能

| 要求 | 内容 |
|---|---|
| R01–R02 | 元ファイルを上書きしない自動保存、次回起動時の復元選択、設定の永続化と初期値復帰 |
| R03–R04 | レイヤーロック・不透明度、共有画素ブロック、全タブの追加履歴メモリ上限と順序を維持した履歴削除 |
| R05–R07 | 補間方式を選べるリサイズ、選択範囲のモザイク・ぼかし・黒塗り、明るさ・コントラスト・彩度調整、プレビュー・取消 |
| R08 | WebP入出力、画質・透過設定、実際のエンコード結果による容量と画像のプレビュー |
| R09–R10 | 筆圧による太さ・濃さ、手ぶれ補正、背景除去の許容差・境界・残す/消す範囲の手直し |
| R11–R12 | 文書別のタブ・保存先・Undo・ズーム、一括変換の進捗・取消・ファイル別結果、衝突を避ける出力名 |
| R13 | OpenAI互換の画像編集・生成消去、接続設定、送信確認・同意、キー保護、日次回数上限、取消、結果確認後の新規レイヤー適用 |
| R14 | 既存台帳を基にしたUIアイコン統一。生成・配置と実寸確認を区別して追跡 |
| R15 | 従来非MSIX配布の維持、MSIX生成・署名・App Installer情報生成、アプリ内更新確認・MSIX取得・ハッシュ検証 |
| R16–R17 | 品質・異常系・配布検証の整備、ブラシ比較および実機依存項目の継続管理、要求・利用者資料の更新 |

PNG/JPEG/BMP/GIFと`.pppaint`の既存経路を維持します。独自形式は新しいレイヤー属性を保持し、旧形式も読み込みます。JPEG/BMPは透過を白背景へ合成します。WebP処理はSkiaSharpを利用し、CPU処理をバックグラウンドで行います。取消時は進行中のネイティブ処理が終了するまで内部処理が残る場合がありますが、画面操作と結果の適用は中止します。

## AIと更新

AIは初期状態では通信せず、キーの入力と送信同意が必要です。APIキーは保存を選んだ場合だけWindows PasswordVaultへ記録します。接続先別に管理し、設定JSONへ含めません。選択のみ送信では選択外を透明化し、全体送信では表示レイヤーの合成を送ります。3分制限と日次回数上限は、サービス側の課金を取り消す機能ではありません。

更新URLは未設定、自動確認はOFFです。更新確認を利用する場合は信頼する配布元URLを設定します。取得前とインストーラー起動前に確認し、署名の信頼確認と実インストールはWindowsへ委譲します。JSONの発行者名とSHA-256は配布元の申告であり、それだけでは署名検証になりません。

標準配布は非MSIXです。MSIX作成にはWindows SDK、正式Publisher、対応する署名証明書が必要です。非MSIX版からMSIX版へは別インストールになる場合があり、既存アプリを自動削除しません。

## 検証と残る確認

Core 215件、Windows Imaging 12件のテストが成功しています。AIと更新のHTTP試験は差し替えハンドラーを使用し、実サービスやOS登録を変更していません。自動復元、WebP保存容量・再読込、タブ、ぼかしUndo、レイヤーロック・不透明度を実画面で確認しました。検証範囲と結果は`dev/v0.2.0-imp.md`に記録します。

以下を完了済みとは扱いません。

- 実APIキーによるAI生成品質・料金・接続権限の確認。
- 公開URL・正式署名証明書を使用した配布、クリーン環境でのインストール・更新・削除。
- 物理ペンの筆圧、複数DPI、スクリーンリーダー、高コントラストの実機受入。
- 実プリンター、共有先、壁紙変更、実ディスク不足、クリップボード非使用環境の最終確認。
- 基準画像とのブラシ描画差分を含む、実画面の最終品質判定。
