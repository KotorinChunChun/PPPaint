# PPPaint v0.3.0

スクリーンショットの切り抜き、注釈、情報隠し、コピー・PNG保存を中心とした構成へ変更した。

- 画像ごとに別ウィンドウで編集する。保存状態、Undo/Redo、ズームはウィンドウごとに独立する。
- 上部に選択、矩形範囲、ペン、消しゴム、矢印、四角、丸、直線、文字、連番、情報隠し、蛍光ペンを配置した。
- 注釈は選び直して移動・四隅からのサイズ変更・色や太さ・文字内容の変更・削除ができる。
- 左下の寸法を押すと画像サイズを変更できる。表示倍率は右下のスライダーで調整する。
- 矩形範囲を指定して切り抜き、範囲コピー、削除できる。範囲削除は白で覆う。
- 「その他」に回転、反転、縦横連結、名前を付けてPNG保存をまとめた。
- 画像の読み込みはPNG/JPEG/BMP/GIF/WebP、保存はPNG。ファイルをドロップして開くこともできる。
- コピーとPNG保存には、注釈と不透明な情報隠しを焼き込む。PNGを再度開いた場合は1枚の画像として扱い、注釈の個別編集は復元しない。
- 色、線の太さ、文字サイズをローカルに保存する。APIキーやアカウントは不要。

フィードバック、アカウント、タブ、レイヤー操作、AI、装飾図形、自由選択、写真加工、背景除去、特殊ブラシ、一括変換、印刷、壁紙設定を廃止した。v0.2.0の資料と旧形式のライブラリ・試験は履歴として保持する。v0.3.0の画面は旧.pppaint/.chunpaint編集形式を開かないため、旧版でPNGへ書き出して利用する。

## キーボード

| 操作 | キー |
|---|---|
| 画像を開く | Ctrl+O |
| 新しい空ウィンドウ | Ctrl+N |
| 画像を貼り付ける | Ctrl+V |
| 画像または指定範囲をコピー | Ctrl+C |
| PNG保存 | Ctrl+S |
| 名前を付けてPNG保存 | Ctrl+Shift+S |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Y |
| 注釈・範囲の削除 | Delete |
| 操作・選択を解除 | Esc |

文字入力欄では通常の文字選択とコピー・貼り付けを優先する。
