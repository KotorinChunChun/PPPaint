# PPPaint v0.2.10

- キャンバス端でも選択枠・ハンドルの外側が欠けないようにし、外側半分からもドラッグできるようにした。
- ハンドルの描画と検知を共通化。四角は見えている四角、丸は見えている円の範囲で検知する。倍率が変わっても画面上の大きさと検知が一致する。
- ハンドルと外周の切り詰め帯が重なる場所は、見えている編集ハンドルを優先。ハンドル以外の灰色の帯では、表示された帯の範囲でキャンバスを切り詰める。
- つかんだ位置からの移動量で操作し、外側をつかんでも開始時に枠が跳ねないようにした。
- 画像・枠・ガイド・消去円の原点を合わせ、余白の無関係な場所では新規描画しない。操作用の表示は保存・コピーに含めない。

[検証記録](../dev/v0.2.10-validation.md)を参照。
