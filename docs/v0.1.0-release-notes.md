# ChunPaint v0.1.0 リリースノート

## リリース候補の範囲

ChunPaint v0.1.0は、Windows 11 x64向けself-contained非MSIXアプリです。9種類のブラシ、レイヤー、選択、テキスト、図形、画像変換、背景除去、Undo/Redo、PNG/JPEG/BMP/GIF入出力、`.chunpaint`プロジェクト保存、画像プロパティのDPI単位換算を含みます。

独自の `src/ChunPaint/Assets/ChunPaintIcon.svg` をアプリ画面へ、複数サイズを含む`src/ChunPaint/Assets/ChunPaintIcon.ico`をEXEの埋め込みアイコンとして、`src/ChunPaint/Assets/ChunPaintCursors.dll`を実カーソル用として使用し、Release成果物へ同梱します。カーソルリソースの読み込みに失敗した場合はシステム矢印へフォールバックします。Microsoft Paint由来のコード、DLL、アイコン、画像は取り込みません。

## 検証済み項目

- Coreテストとプロジェクト保存／読込、壊れた入力の拒否
- Win2DによるPNG／JPEG／BMP／GIFの実バイト列保存・再読込と形式別のアルファ／色許容差
- 9種類のブラシプロファイル、決定的な描画点列、種類別パターン、ピクセルペンの整数座標
- Release構成のアプリ直接x64ビルドとソリューションビルド
- `-SmokeLaunch`による公開候補プロセスの起動・生存確認（ウィンドウ可視性はUIセッション依存）
- Release成果物の完全なself-contained x64直接ビルド出力、ChunPaint実行ファイル／DLL／独自SVG／ICO、0.1.0メタデータ、x64 PE形式
- ソースとRelease成果物の禁止参照検査
- ユーザー単位インストール／アンインストールスクリプトの構文、同梱物、関連付け契約、`-WhatIf`無変更実行
- 品質ゲートとcapture-index/hash整合性

再現コマンド:

```powershell
pwsh -NoProfile -File dev/release/Invoke-ReleaseValidation.ps1
```

## 未構成・実機依存

`WindowsPackageType=None` のため、MSIX、署名証明書、正式publisher identity、自動更新はこのリリース候補に含まれません。Release成果物の`Install-ChunPaint.ps1`は現在のユーザーの`%LOCALAPPDATA%\Programs\ChunPaint`へ登録し、`.chunpaint`関連付け、`chunpaint://open/?path=...` プロトコル、上書き更新、Windowsのアンインストール情報を設定します。関連付け／プロトコルから渡されたプロジェクトは起動引数経路で開きます。クリーン環境での実登録は未確認です。

Windows実機でのDPI／アクセシビリティ、ディスク不足、保存取消、プリンター／クリップボードなし、共有UI、壁紙設定、印刷確定、クリーン環境への実登録は、外部状態を変更または実機環境に依存するためRelease自動検証では確定しません。画像コーデックの画素往復、JPEG/BMPの不透明化、JPEG/GIFの色誤差はWindows統合テストで検証します。9種類のブラシは決定的な計算とUI契約を検証済みですが、Paint代表画像とのピクセル差分による高精度再現判定は継続課題です。

## 安全とプライバシー

アプリは管理者権限を要求せず、外部AIは未接続です。画像を外部サービスへ送信せず、APIキーや認証情報を保存しません。詳細は [PRIVACY.md](../PRIVACY.md) と [LICENSE](../LICENSE) を参照してください。
