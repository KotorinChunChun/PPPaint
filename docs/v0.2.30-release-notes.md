# PPPaint v0.2.30

全面的なリファクタリングと不具合修正の版です。画面の構成とキー操作は変わりません。

## 修正

- 表示倍率が100%以外のときに画像をドラッグで移動すると、画像が画素の境界からずれ、表示・コピー・保存した画像がぼやけていました。移動は1画素単位になり、画像の画素を保ちます。
- 貼り付け・画像の重ね・ドロップで画像を中央などへ置くとき、大きさの差が奇数だと0.5画素ずれてぼやけていました。常に画素の境界へ置きます。
- 矩形範囲は画素の境界に合わせて表示します。削除・切り取り・切り抜きは表示中の枠と同じ画素を処理します。これまでは表示倍率や画面の拡大率によって、最大1画素ずれることがありました。
- 文字・吹き出し・透かしの文字欄での入力は、欄を離れるまでの一続きを1回の「元に戻す」で取り消せます。これまでは1文字ごとに履歴が増え、長い文を入力すると入力前の操作まで戻せなくなっていました。
- 起動時の引数や外部管理の「開く」は、開けない旧形式（`.pppaint`／`.chunpaint`）を最初から受け付けません。

## 内部の整理

- 2026-10-29に提供しないと決めた機能（写真補正、背景除去、グラデーション、特殊ブラシ、一括変換）と、旧レイヤー編集・旧プロジェクト形式・自動更新の使われていないコードと試験を削除しました。WebPは読み込みだけに対応し、保存はPNG/JPEGです。
- 回転・反転や文字枠の自動拡張などの計算を画面のコードから分離し、自動試験を追加しました。

## 起動

`artifacts/release/v0.2.30/win-x64/Start-PPPaint.cmd` を使います。旧版で未保存の画像を編集中の場合は、同じフォルダーの `Start-PPPaint-Parallel.cmd` で別の設定先（`profiles\editor-v0.2.30`）を使って起動できます。

詳細は[実装・検証記録](../dev/v0.2.30-imp.md)を参照してください。
