# v0.2.33 変更内容

- クリップボードに貼り付け可能な画像がない場合、貼り付けボタンと横の▼をグレーアウトします。空や文字のみの状態から画像をコピーすると、有効状態へ追従します。
- Ctrl+V／Ctrl+Shift+Vも実行直前に確認し、画像がない場合はメニューやエラー画面を出しません。
- 背景の透明指定はPNGのアルファ値として保存されることを確認しました。初期の白背景は不透明で、読み込んだ画像の不透明な白を自動で透明化するものではありません。背景色の保存動作は変更していません。

検証結果は [実装報告](../dev/v0.2.33-imp.md)、操作は [利用ガイド](user-guide.md) を参照してください。
