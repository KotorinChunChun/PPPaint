# PPPaint v0.2.16

- ペンと消しゴム、矢印などの幅を別々に記憶する。文字サイズ・ぼかし/モザイク強度・不透明度もツールごとに保存し、再起動後に復元する。
- 既存の共有設定は最初の値として移行する。既存図形の再選択は表示だけで、ツール既定値を書き換えない。数値を編集したときだけ該当ツール・該当項目を記憶する。
- 消しゴムは四角い範囲を画素に揃えて完全に置換する。1ドットはポインタを含む1画素を消し、透明背景では透明へ戻す。幅は整数に揃える。
- ペンは鉛筆、スポイトはスポイトの独自カーソルを使う。先端が操作点になる。消しゴムのネイティブなプラスは出さず、実際に消える四角を表示する。
- 番号は画像ごとに1から開始し、次番号を設定ファイルへ保存しない。

Microsoft Paintの素材抽出・再配布の許可は確認できないため流用していない。[Microsoftの著作物利用条件](https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions)を参照し、カーソル資産は独自に生成した。
