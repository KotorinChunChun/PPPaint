# キー割当と根拠

v0.2.13。描画ツール名の括弧内の文字に下線を付け、ツールチップとアクセシビリティ情報にもキーを表示する。ツールバー1行目は操作名だけを表示し、キーをツールチップだけに出す。ツールは文字キー単独とAlt+同じ文字で切り替えられる。文字・数値の入力欄では単独キーを実行しない。

## ツール

| 操作 | キー | 採用理由 |
|---|---|---|
| 選択・移動 | V | Photoshopの移動 |
| 矩形範囲 | M | Photoshopの矩形選択 |
| ペン | B | Photoshopのブラシ（自由描画） |
| 消しゴム | E | Photoshopの消しゴム |
| 矢印 | A | Greenshotの矢印 |
| 四角 | R | Greenshotの矩形 |
| 直線 | L | Greenshotの直線 |
| 文字 | T | PhotoshopとGreenshotの文字 |
| 蛍光ペン | H | Greenshotのハイライト |
| 丸 | O | Eは消しゴムで使うため、丸を連想しやすいOへ独自割当 |
| 番号 | N | Numberから独自割当 |
| 情報隠し | K | BlackoutのKを独自割当 |
| 矩形ぼかし | F | Filterから独自割当 |
| 吹き出し | Q | Quoteから独自割当 |
| モザイク | X | PixelのXから独自割当 |
| 透かし | S | Stampから独自割当。保存はCtrl+S |

V/M/B/E/Tの根拠は [Adobe公式ショートカット表](https://helpx.adobe.com/content/dam/help/en/photoshop/using/default-keyboard-shortcuts/photoshop-keyboard-shortcuts.pdf)、A/R/L/T/Hの根拠は [Greenshot公式ヘルプ](https://getgreenshot.org/help/)。複数製品の割当は衝突するため完全互換ではない。O/N/K/Fは一般標準と称さず、本アプリの固定割当として扱う。

## 共通コマンド

注釈文字欄のEscは、入力内容と選択を保持して画像編集へフォーカスを戻す。IME変換中は変換操作を優先する。「全体」（Alt+W）は表示領域の変化へ追従し、もう一度押すか手動倍率指定で解除する。

「選択・移動」（V）は図形・貼り付け画像を対象にする。空白からのドラッグで複数を囲めるが、画像上のドラッグは画像の移動になる。「矩形範囲」（M）は画像上からでも任意の矩形を作り、切り抜き・切り取り・削除へ使う。用途が異なるため両方を維持する。

Ctrl+N（新規）、Ctrl+O（開く）、Ctrl+V（貼付）、Ctrl+C（キャンバス全体の画像コピー）、Ctrl+A（キャンバス全体の範囲選択）、Ctrl+X（選択範囲または選択対象の切り取り）、Ctrl+S（PNG/JPEG保存）、Ctrl+Shift+S（名前を付けて保存）、Ctrl+Z / Ctrl+Y（Undo/Redo）、Delete（削除）、Esc（取消・選択へ戻る）を維持する。

矩形範囲がある場合はCまたはEnterで切り抜く。GreenshotもCをトリミングに割り当てている。Alt+Gでその他、Alt+Pで設定、Alt+Iで色、Alt+Jで重なり、Alt+Wで全体表示、Alt+Dで原寸、Alt+Zでキャンバスサイズを開く。これらのAlt文字割当はツールキーとの衝突を避ける本アプリの規則である。

## 修飾キー（v0.2.5）

| 操作対象 | 修飾キー | 動作 |
|---|---|---|
| 選択 | Ctrl/Shift＋クリック | 選択を追加・解除。クリックだけでは複製しない |
| 選択した図形・画像の移動 | Ctrl＋ドラッグ | 元を保持して複製。複数選択は相対位置と順番を保持 |
| 移動 | Shift＋ドラッグ | 横または縦の大きい移動方向へ固定 |
| 矩形・範囲の新規描画 | Shift | 正方形に固定 |
| 矩形・範囲の新規描画 | Ctrl | 開始位置を中心に描く |
| 選択枠の8方向ハンドル | Shift | 元の縦横比を固定 |
| 選択枠の8方向ハンドル | Ctrl | 元の中心を固定 |
| 描画・サイズ変更 | Ctrl＋Shift | 中心基準と比率固定を併用 |
| 移動・描画・サイズ変更 | Alt | キャンバス/非選択オブジェクトの辺・中心へ吸着し、ガイドを表示 |

吸着の許容距離は表示上6px。複合時はShiftの軸・比率固定を優先し、成立した吸着だけをガイド表示する。修飾キーの押下・解放はドラッグ中のプレビューへ反映する。Ctrl複製はマウスを離す時点でもCtrlを保持する。移動・複製・サイズ変更はマウスを離すと1操作として確定し、Esc/キャプチャ喪失では変更と選択を戻す。重なった対象の選び直しは右クリックの「選択する対象」を使う。

## 修飾キーの根拠

Office公式は、ハンドルのShiftドラッグで比率固定、Ctrlドラッグで中心を固定、Ctrl+Shiftで両方を適用すると説明している。[Microsoft公式](https://support.microsoft.com/en-us/office/graphics-visuals/change-the-size-of-a-picture-shape-text-box-or-wordart)

Excel公式はCtrlドラッグによる複製と、Altでセルの格子へ合わせる操作を説明している。[Microsoft公式](https://support.microsoft.com/en-us/excel/group-copy-move-or-align-controls-on-a-worksheet)

本アプリにセルはないため、Altの位置合わせはキャンバスと既存図形への吸着へ置き換える。この置き換えとCtrl/Shiftクリックの選択切替は、本アプリ向けの設計であり、Excelとの完全互換ではない。ユーザーの回答により修飾キー一式をv0.2.5へ追加した。

## ダイアログ

Tab/Shift＋Tabで項目移動、Enterで既定操作、Escで取消。確定はAlt＋S、保存せずに閉じるはAlt＋N、その他の副操作はAlt＋D、取消・閉じるはAlt＋C。キー部分に下線を付け、ツールチップにはEnter/Escも表示する。未保存破棄・上書きの確認は取消を既定にし、Enterだけで破棄や上書きを確定しない。

ファイル画面はAlt＋Lでフォルダー、Alt＋Nでファイル名、Alt＋UまたはAlt＋↑で上位へ移動する。一覧は矢印で選択し、Enterでフォルダーへ入るかファイルを確定する。フォルダー欄のEnterはその場所へ移動する。寸法画面はAlt＋W/Hで幅/高さ、Alt＋Rで縦横比固定を切り替える。設定画面の初期化もAlt＋R。入力中は背後の編集ツールへキーを渡さない。

Enterの既定ボタンと入力欄による処理は[Microsoftのダイアログ仕様](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/dialogs-and-flyouts/dialogs)、Altアクセスキーのスコープは[Microsoftのアクセスキー仕様](https://learn.microsoft.com/en-us/windows/apps/develop/input/access-keys)に従う。S/D/Cおよび各欄の文字割当はこのアプリの規則。

## v0.2.7の追加操作

- Ctrl+Cは範囲選択の有無によらず、キャンバスと同じ寸法の画像をコピーする。Ctrl+Xは選択範囲をコピーして削除し、範囲がない場合は選択した対象を切り取る。コピーに失敗した場合は削除しない。入力欄では通常の文字の選択・コピー・切り取りを優先する。
- Ctrl+Vは現在のキャンバスに重ねる。同一プロセスで最後にコピーした内容がクリップボードに残っている場合、画像と図形を個別に保持する。外部アプリでクリップボードを変更した場合は画像として読み込む。
- キャンバスの辺をCtrl+ドラッグすると、中心を保ち反対辺も同量切り詰める。画像の解像度は変えない。図形のCtrl中心基準と同じ操作規則を適用している。
- Ctrl+ホイールでポインタ位置を基準に表示倍率を10～400%へ変更する。画像の画素寸法は変わらない。
- 左下の背景色はAlt+U。背景ダイアログの透明切替はAlt+T、白へ戻す操作はAlt+W。背景は画像の背後にあり、読み込んだ画像の不透明な画素自体は塗り替えない。
- 番号ツールの開始番号欄で次の値を設定する。押したままドラッグすると配置をプレビューし、離すと確定、Escで取り消す。
- 文字・吹き出し・透かしをダブルクリックすると文字欄へフォーカスする。
## v0.2.8の追加キー

- Ctrl+Shift+Xで矩形選択範囲をキャンバスとして切り抜く。C/Enterによる切り抜きも維持する。Ctrl+Xはコピーして削除する切り取りのまま。
- 保存せずに閉じるは下線付きのN（Alt+N）。既定操作は取消で、Enterだけでは破棄しない。
- スポイトはIで開始・解除し、キャンバス上のクリックで合成色を取得して元のツールへ戻る。Escでも解除する。Iは[Adobe公式のPhotoshop Webの表](https://helpx.adobe.com/ph_fil/photoshop/web/get-set-up/preferences-and-settings/keyboard-shortcuts.html)に合わせた。既存の色編集Alt+Iは維持する。
- パレット色をクリックすると選択枠を表示する。ダブルクリック、右クリックの「この色を編集」、選択後の「色」（Alt+I）から同じスロットを編集できる。色編集のRGB欄はAlt+H、適用はAlt+S、取消はEsc/Alt+C。
キャンバスサイズ画面の両端連動はAlt+B（既定ON）。縦横比固定Alt+Rとは独立している。数値変更は画像を拡大縮小せず余白追加/切り詰めをプレビューし、適用Alt+Sで確定、Esc/Alt+Cで元の寸法・表示へ戻る。
