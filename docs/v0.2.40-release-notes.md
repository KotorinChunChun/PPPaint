# PPPaint v0.2.40

- キャンバスに接する8方向のハンドルから、キャンバスのサイズを変更できます。
- バケツを復活させました。カラーパレットとスポイトは右ボタンで色2を選べます。ペン・バケツ・矢印などを右ボタンで使うと色2で作図します。
- 矢印は描画後も選択されたままです。バケツと矢印に専用カーソルを追加しました。
- オブジェクト一覧から背面にある図形も選択できます。全ハンドル表示で位置を確認できます。名前をドラッグするか右クリックすると重なり順を変更できます。
- Ctrl＋クリックで複数選択し、まとめて移動できます。「選択・移動（V）」はオブジェクトを動かし、「矩形範囲（M）」は囲った画素を切り離して動かせます。

Windows 11 x64用です。インストーラーは開発者の自己署名証明書で署名しています。発行元を信頼していないPCではWindowsが警告する場合があります。既存のインストールを更新するときは、作業を保存してPPPaintを終了してから実行してください。
