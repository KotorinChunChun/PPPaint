# 使い方

対象はPPPaint v0.2.34です。起動方法は[README](../README.md)、キーの一覧と採用根拠は[キー割当](keyboard-shortcuts.md)を参照してください。

## スクリーンショットを編集して渡す

1. 撮影した画像をクリップボードへコピーし、PPPaintで **Ctrl+V** を押します。
2. **矩形範囲（M）** で必要な部分を囲み、**切り抜き（Ctrl+Shift+X）** を実行します。
3. 矢印・四角・文字・番号などを追加します。氏名などを覆う場合は、不透明に塗りつぶす **情報隠し（K）** を使います。
4. **Esc** で選択を解除して **Ctrl+C** を押すと、キャンバス全体を画像としてコピーできます。ファイルにする場合は **Ctrl+S** で保存します。

## 画像の取り込みと連結

| 操作 | 結果 |
|---|---|
| ファイル▼ → 新規／Ctrl+N | 新しいウィンドウを開く |
| ファイル▼ → 開く／Ctrl+O | PNG・JPEG・BMP・GIF・WebPを開く。編集中なら別ウィンドウへ開く |
| 貼り付け／Ctrl+V | 現在のキャンバスへ重ねる。必要に応じてキャンバスを広げ、縮小はしない |
| 貼り付け横の▼／Ctrl+Shift+V | 「重ねる・上に連結・下に連結・左に連結・右に連結」から選ぶ |
| 画像ファイルのドロップ | 現在の文書へ追加する。空の新規文書なら取り込んだ画像を最初の画像にする |
| その他▼ → 画像を重ねる | ファイルを選んで現在の文書へ追加する |

クリップボードに貼り付け可能な画像がない場合、貼り付けと横の▼はグレーアウトします。内容を画像へ変えると有効になります。Ctrl+V／Ctrl+Shift+Vも画像がない場合は何も実行しません。

貼り付けた画像は選択状態になります。そのまま移動・サイズ変更できます。連結メニューは上下キーで選び、Enterで実行、Escで取り消します。

## 選択と矩形範囲

**選択・移動（V）** は図形や画像そのものを選びます。クリックで選択し、ドラッグで移動します。四角いハンドルでサイズ変更、線・矢印の端点で向きと長さを変更できます。空白から囲むと複数を選べます。画像の上からドラッグすると、その画像の移動になります。ドラッグでの移動は表示倍率にかかわらず1画素単位で、移動によって画像がぼやけることはありません。

**矩形範囲（M）** は画像の上からでも長方形の範囲を指定できます。切り抜き・範囲の切り取り・削除に使います。ハンドルで範囲を広げたり狭めたりできます。範囲は画素の境界に合わせて表示し、処理する画素は表示中の枠と同じです。

| 目的 | 操作 |
|---|---|
| 複数選択の追加・解除 | CtrlまたはShiftを押しながらクリック |
| 複製して移動 | Ctrlを押したままドラッグし、Ctrlを保持して離す |
| 正確な移動 | 選択後に矢印キーで1px、Shift+矢印キーで10px |
| 重なった対象の選び直し | 右クリック → 選択する対象 |
| 前後の順序変更 | 重なり▼、または右クリックメニュー |
| 選択解除 | 選択・移動で何もない場所をクリック、またはEsc |
| まとめて1枚の画像にする | その他▼ → 選択を画像に統合／Ctrl+E。背景は透過で、Undoで元の図形へ戻せる |

統合した画像は、選択対象の中で最前面だった位置へ置かれます。重なり順が離れた図形を選ぶと、間にあった未選択図形との重なり方が変わります。ぼかし・モザイク・消しゴムを一緒に統合する場合、その効果対象は選択した図形だけです。

Shiftによる比率・方向固定、Ctrlによる中心基準、Altによる位置合わせなどは[修飾キー一覧](keyboard-shortcuts.md#図形と矩形範囲の修飾キー)を参照してください。

## 描画と設定の変更

矢印・四角・丸・直線はドラッグして描きます。ペンは自由描画、消しゴムはポインタに表示される四角い範囲を消去します。蛍光ペンは下の内容を残して強調します。ぼかし・モザイクはドラッグした矩形に適用します。

文字は配置する場所をクリックし、吹き出しはドラッグして作ります。文字の不透明度は既定100%で、5～100%へ変更できます。内容は上部の文字欄で編集します。文字欄での入力は、欄を離れるか保存するまでの一続きを1回の「元に戻す」で取り消せます。Ctrl+S後に続けて入力した分は、保存時の内容まで戻せます。作成済みの対象をダブルクリックすると、その文字欄へ移ります。番号はクリック位置を中心に配置し、押したままドラッグすると位置を確認してから確定できます。「次の番号」の値を変えると、その番号から続けられます。新しい画像では1から始まります。

選択中に色・太さなどを変えると、選択対象に適用されます。選択を解除すると、新しく描くための設定へ戻ります。複数選択で値が異なる場合は「混在」と表示し、変更した属性だけを対応する対象へ適用します。

太さの既定は全ツール3です。ペンでは、描く位置に新規作図用の色・太さと同じ●が追従します。鉛筆カーソルも表示します。1pxでは実際に描く1画素を示します。この●は表示用で、画像のコピー・保存には入りません。

太さ・文字サイズ・ぼかし強度・モザイクの粗さ・文字の不透明度は、ツールごとに独立して記憶し、再起動後も復元します。新規作図の色はツール間で共通です。選択した図形1つの設定を今後の作図へ使いたい場合は、**設定を取得（Alt+Y）** を押します。

パレットはクリックで選択し、選択色に枠が付きます。ダブルクリック、右クリックの「この色を編集」、または「色」（Alt+I）でパレット色を編集できます。**スポイト（I）** はキャンバス上をクリックして合成後の色を新規作図色へ取り込みます。図形の太さや文字サイズも取り込む「設定を取得」とは用途が異なります。

## コピー・切り取り・切り抜き

| コマンド | 対象と結果 |
|---|---|
| Ctrl+A | キャンバス全体を矩形範囲として選択 |
| Ctrl+C：図形選択のみ | 選択した図形・画像だけを囲む矩形をコピー。背景は透過 |
| Ctrl+C：矩形範囲あり、または無選択 | キャンバスと同じ寸法の全体画像をコピー |
| Ctrl+X | 矩形範囲があればその範囲をコピーして削除。範囲がなければ選択対象をコピーして削除 |
| Delete | 矩形範囲があればその範囲を削除。範囲がなければ選択対象を削除 |
| Ctrl+Shift+X／C／Enter | 矩形範囲、または選択図形すべてを囲む範囲を新しいキャンバスにする |

切り抜きは矩形範囲が優先されます。図形の外周で切り抜く場合は、キャンバス内の線幅や矢印の先端も含めます。「切り抜き」が無効なら、矩形範囲または図形・画像を選択してください。

Ctrl+XはCtrl+Cと同じ画像寸法になるとは限りません。現行版の図形だけの切り取りは、選択対象をキャンバス寸法でコピーする動作です。選択図形を余白なしで複製する場合はCtrl+Cを使います。

外部へ渡すコピーは1枚のラスタ画像です。同じアプリプロセスで最後にコピーした内容がクリップボードに残っていれば、貼り付け後も図形を個別に編集できます。別プロセス・アプリ終了後・他のコピーで置き換えた後は、その編集情報を引き継ぎません。

## キャンバスの寸法と背景

キャンバス外側の白い四辺・四隅をドラッグすると、内側へ切り詰めたり、外側へ余白を追加したりできます。Ctrlを押すと対角側も同量変更します。これは画像内容の拡大縮小ではありません。

数値で調整する場合は、左下の寸法表示または **Alt+Z** から「キャンバスサイズ」を開きます。

- 幅・高さは1px単位です。元の数値と差を表示し、増加は青、減少は赤で示します。
- 「縦横比を固定」は既定OFFです。ONにすると、幅の変更に高さも連動します。
- 「両端を連動」は既定ONです。中心を基準に左右・上下を増減します。
- 8方位のプレビューのうち、四隅は縦・横それぞれ画像内容80%・外側余白20%を初期表示します。各辺中央の4枠は、境界に直交する方向で80%／20%です。画像が表示範囲より小さい場合は、反対側の外側も見えます。
- 元の境界は橙の破線、変更後の境界は青い線です。切り取られる内容は暗く表示され、確認できます。
- 青い境界をドラッグして調整できます。画像の表示位置は固定され、境界と切り取り部分の暗さだけが変わります。
- 「プレビュー倍率」は既定1倍、0.25～16倍です。枠の大きさを保ったまま映す画素範囲を変えます。1倍なら100×100px、4倍なら25×25pxを表示します。
- 「リセット」（Alt+E）は未適用の寸法・位置・倍率・オプションを開始時へ戻し、画面を開いたままにします。
- 「適用」（Alt+S）で確定します。適用前の本体キャンバスは変わりません。「キャンセル」（Esc／Alt+C）で閉じ、適用後はCtrl+Zで戻せます。

左下の **背景（Alt+U）** で背景色と透明を変更できます。初期色は白（255,255,255）で不透明です。「透明」にすると、画像や図形で覆われていない部分のアルファ値は0になります。PNG保存では透明・半透明を維持します。JPEG保存では白へ合成します。背景は読み込んだ画像の背後にあるため、元画像の不透明な白い部分は塗り替わらず、自動で透明にもなりません。

## 表示を拡大して編集する

右下のバーまたは **Ctrl+ホイール** で10～400%へ拡大縮小します。画像の画素寸法は変わりません。**全体（Alt+W）** は画像を表示領域に合わせ、ウィンドウの大きさにも追従します。**Alt+D** で100%表示に戻ります。

Spaceを押しながらドラッグ、またはマウスの中ボタンドラッグで表示位置を動かせます。

## 保存と終了

**保存（Ctrl+S）** または **ファイル▼ → 名前を付けて保存（Ctrl+Shift+S）** を使います。保存形式は拡張子で指定し、PNGとJPEGに対応します。画素や透明を保持したい場合はPNGを使用します。

保存した画像には注釈や情報隠しを焼き込みます。PNG/JPEGを開き直しても、図形ごとの編集状態は復元しません。既存ファイルの上書き時は保存前の画像をバックアップし、「その他▼ → 保存前の画像を開く」から確認できます。バックアップには加工前の内容が残ります。保存中に元ファイルの外部変更を検出した場合は、別名保存へ案内します。

未保存の画像を閉じるときは「保存（S）」「保存せずに閉じる（N）」「キャンセル（C）」を選びます。この確認ではNまたはAlt+Nで破棄して閉じ、Enter／Escでキャンセルします。通常の文字・数値入力画面では、単独文字を確認操作に使いません。

保存先・設定・クリップボードの扱いは[プライバシーと権限](../PRIVACY.md)を参照してください。
