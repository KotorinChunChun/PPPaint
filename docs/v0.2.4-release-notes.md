# PPPaint v0.2.4

画像と図形を同じキャンバスで重ねて編集する操作へ変更した。

- Ctrl+V・貼り付けは現在のキャンバスへ追加する。既存画像を別ウィンドウへ追い出さない。
- ファイルのドロップはドロップ位置へ画像を重ねる。「その他」の「画像を重ねる」からも追加できる。
- 元画像、貼り付け画像、図形、文字、ペンをそれぞれ選択・移動・サイズ変更・削除できる。
- 矢印・直線は両端の丸いハンドル、画像や枠図形は四隅と辺中央のハンドルで編集する。
- 描いた図形は自動的に選択ツールへ切り替わり、そのまま調整できる。ペンと消しゴムは連続して使える。
- 「範囲」で囲んだ対象は枠で可視化され、範囲内からドラッグしてまとめて動かせる。切り抜き・範囲コピーも引き続き使える。
- 選択中の「重なり」または右クリックで、最前面・1つ前・1つ後ろ・最背面へ変更できる。
- 枠図形の内側の空白と画像の透明部分では、その下の対象を選べる。選択済みの枠は内部からドラッグして動かせる。
- アプリ内で選択対象をコピーした場合、クリップボードが変更されるまでは編集可能な対象として貼り付けられる。他のアプリへは合成した画像を渡す。
- 保存時は1枚のPNGに焼き込む。開き直した後の個別編集情報は保持しない。

「開く」「新規」は独立文書のウィンドウを作る。貼り付け・画像挿入・ドロップは現在の文書を編集する。

## 選択と移動のキー操作

| 操作 | キー |
|---|---|
| 対象を追加選択・選択解除 | Shift+クリック |
| 背景画像の上から囲んで選択 | Ctrl+ドラッグ |
| 重なった対象を順に選択 | Alt+クリック |
| 全対象を選択 | Ctrl+A |
| 対象を1px移動 / 10px移動 | 方向キー / Shift+方向キー |
| 直線・矢印の方向や図形の比率を固定 | Shift+ドラッグ |
| 対象を1つ前 / 1つ後ろへ | Ctrl+PageUp / Ctrl+PageDown |
| 対象を最前面 / 最背面へ | Ctrl+Shift+PageUp / Ctrl+Shift+PageDown |
| キャンバス表示をドラッグ | Space+ドラッグ / 中央ボタンドラッグ |
| 操作を取り消す | Esc |

検証済み範囲と実機操作の残件は [検証記録](../dev/v0.2.4-validation.md) に記載する。
