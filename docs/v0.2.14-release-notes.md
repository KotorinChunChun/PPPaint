# PPPaint v0.2.14

- 太さ1のペンでクリックすると、ポインタを含む画像の1画素を指定色で描く。小さな円のアンチエイリアスで複数画素へ薄く広がる不具合を修正した。
- 連続線も画素中心を結び、太さ1のまま接続する。太さ2以上や他の図形は従来の滑らかな描画を維持する。
- 編集中も保存と同じ合成画像を表示する。拡大時の画素は最近傍補間で表示し、保存・再読込前後のにじみ方の違いを防ぐ。
- PNGでは1画素の色・寸法・透明度を保存後も保持する。JPEGは非可逆圧縮のため、正確な画素保持にはPNGを使用する。

画像の画素寸法と表示倍率は別の設定。拡大表示では1画素が大きく見え、縮小表示では細かな画素を表示できない場合がある。
