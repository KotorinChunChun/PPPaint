# PPPaint v0.2.35

- ペンで描画中の矩形枠を非表示にし、描線と描画位置のプレビューを維持しました。
- V/Mで囲った範囲をドラッグすると、ペン・図形を含む見えている内容を画像として切り離して移動できます。Ctrl複製、Shift方向固定、Alt位置合わせ、Esc取消、Undoに対応します。
- スポイトは押したままドラッグすると色見本とHEXを表示し、離した地点の色で確定します。
- 情報隠しを四角▼の不透明な塗りつぶしへ統合しました。K／Alt+Kは引き続き利用できます。
- 矢印▼に線・両端・太いブロック・陰影付き立体の4種類と塗りつぶしを追加しました。丸▼で輪郭／塗りつぶし、番号▼で丸／四角／囲みなしと塗りつぶしを選べます。
- 吹き出しは本文8方向と、尾の先端・付け根2点を調整できます。上部の専用文字欄で複数行を入力でき、文字量に合わせて本文枠が広がります。

図形の新規作図スタイルは再起動後も保持します。選択図形のスタイル変更は新規作図設定を置き換えません。今回の設定引継ぎでは太さを再初期化しません。

範囲の切り離し時は既存のぼかし・モザイクを画像へ固定して範囲外の見た目を維持し、その他の範囲外図形は編集可能なまま残します。PNG/JPEG保存では従来どおり全体を1枚の画像へ焼き込みます。
