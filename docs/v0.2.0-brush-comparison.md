# v0.2.0 ブラシ描画の比較手順と結果

## 今回確認したこと

`src/PPPaint/MainWindow.TextAndBrushes.cs`に9ブラシの描画分岐とDrawメソッド、`src/PPPaint.Core/BrushStrokePlanner.cs`に決定的な描画点計画があります。既存の`BrushStrokePlannerTests`はプロファイルと点列を検証しますが、最終ラスタ画像そのものの一致を確認するものではありません。

既存の`docs/mspaint-observed-spec.md`と`docs/widget-implementation-audit.md`には比較対象の操作・ブラシ一覧と差分確認の残件があります。保存済みキャプチャーはメニューや画面状態が中心で、今回の固定点列・寸法・色・線幅と一致する9ブラシの基準画像は確認できませんでした。既存画像を基準画像として流用したり、参考画像を変更・公開したりしていません。

## 追加したツール

`dev/quality/New-BrushComparison.ps1`は、実アプリの描画switch、各Drawメソッド、ScaleAlphaを実行時にソースから抽出し、独立したWin2Dテストプロジェクトをartifacts配下に生成します。ブラシ描画を別実装へ置き換えません。抽出境界が変わった場合はエラーにして、古いコピーで比較を続けないようにします。

固定条件は512×160画素、96DPI、白背景、色ARGB #FF2864B4、基本幅4、61点の固定した正弦曲線です。圧力・手ぶれ補正は無効、Win2Dソフトウェアレンダラーを使います。実際の入力イベントの間隔・筆圧・画面DPI・表示倍率・GPU描画の検証は含みません。

```powershell
cd C:\develop\KotorinToys\tools\PPPaint
pwsh -NoProfile -File dev/quality/New-BrushComparison.ps1
```

出力先は毎回新規の`artifacts/brush-comparison-識別子`です。明示する場合も未作成のartifacts配下に限定し、既存出力は上書きしません。

出力:

- Oil / Watercolor / Marker / NaturalPencil / Airbrush / Calligraphy / Crayon / Flat / Pixel の9枚のPNG。
- `comparison.json`：点列・描画条件・画素SHA-256・同条件2回描画の一致・参照との差分値。
- `source-hashes.json`：抽出元描画コードと点列コードのSHA-256。
- `generator/`：抽出された実コードと実行したテストプロジェクト。

## 基準画像との差分

参照フォルダーへ上記と同名のPNGを用意し、次のように指定します。参照ファイルは読取のみで、コピーや書換えをしません。差分画像はローカルartifactsへ生成し、公開処理は行いません。

```powershell
pwsh -NoProfile -File dev/quality/New-BrushComparison.ps1 -ReferenceDirectory C:\private\brush-reference
```

参照の寸法が512×160でなければ停止します。自動的な位置合わせ・拡大縮小・切り取り・色補正は行いません。存在しないブラシの参照は未提供として記録します。比較したものは変更画素数、BGRA各成分の最大絶対差・平均絶対差と`difference-ブラシ名.png`を出力します。差分PNGはRGBの絶対差を表示するため、アルファ成分だけの差は数値側で確認してください。

## 実行結果（2026-09-12）

- `artifacts/brush-comparison-v020-check`：fixtureテスト1件成功。9種類すべてで同条件の2回描画が完全一致。
- `artifacts/brush-comparison-v020-diff-check`：前項の自作fixtureを参照にして再実行、テスト1件成功。9種類すべて変更画素0・最大成分差0。
- Watercolorの出力を画像として開き、白地の青い曲線が生成されていることを確認。
- パッケージ復元でNuGet脆弱性情報への接続警告とテスト用PRI言語警告が出ています。テスト自体は成功しました。

この結果は自実装の再現性と差分ツールの正常系を確認したものです。本家と一致した結果ではありません。

## 本家との比較で必要な条件

本家のバージョン、対応ブラシ、同じ画素寸法・背景・色・基本幅、全61点の入力順序とイベント間隔、圧力無効、補正条件、画像保存形式を揃えた参照が必要です。ブラシによって本家側が乱数を使う場合は複数回の出力も必要です。

参照取得後は、差分の最大値だけでなく線幅・被覆率・粒子・透過の特徴を視認し、ブラシごとの許容差を先に合意してから判定します。現時点ではその同条件参照と許容差がなく、本家のピクセル一致・高精度再現は未判定です。R17の比較基盤は追加しましたが、その受入判定を完了済みとは扱いません。
