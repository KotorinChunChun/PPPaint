# PPPaint v0.2.6

- 吹き出し(Q)、モザイク(X)、透かし(S)を追加。個別に再選択・移動・サイズ変更・重なり順変更・複製・削除できる。
- 吹き出しの丸い尾ハンドルで指す位置を変更できる。文字・線幅・色も再編集できる。
- モザイクは矩形より下の合成画像へ作用し、粗さを変更できる。透かしは文字・色・サイズ・不透明度を変更できる。
- PNG/JPEGは元の形式で保存する。別名保存では拡張子でPNG/JPEGを選ぶ。透明部分をJPEG保存する際は白背景に合成する。
- 保存時に元ファイルの変更・削除を検出した場合は上書きせず、編集を保持して別名保存を選べる。
- 上書き前の画像は同じフォルダーへ `名前.pppaint-backup-日時-識別子.拡張子` で保持する。「その他」の「保存前の画像を開く」で確認できる。
- 保存失敗時は画像・注釈・Undoを保持し、再試行できる。保存・コピーの出力は1枚のラスタ画像で、保存後も現在のウィンドウ内では注釈を再編集できる。
- ツールバー1行目はキーをキャプションから外し、ツールチップに表示する。描画ツールとダイアログのキー表示は維持する。

ユーザー指定により、SPMZ形式とWeb/iframe/文書埋め込み連携は追加しない。新しいプロジェクト形式も追加していない。

[キー一覧と根拠](keyboard-shortcuts.md)、[実装報告](../dev/v0.2.6-imp.md)を参照。
