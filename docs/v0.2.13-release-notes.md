# PPPaint v0.2.13

- 共通操作を上段、描画ツールを中央、色・太さ・文字や効果の設定を下段へ整理。
- 上部ツールバーの横スクロールをなくし、ウィンドウ幅に応じて改行。標準幅では描画ツールが2行になる。
- スポイトは描画ツール側、切り抜き・削除・重なり順は共通操作側へ移動。上段のキーはツールチップだけに表示。
- ツールに使用できない太さの入力欄は非表示にし、設定値は保持する。

| ツール | 使い分け |
|---|---|
| 選択・移動（V） | 図形や貼り付け画像を選び、移動・サイズ変更・重なり順変更を行う。空白から囲んで複数の対象も選べる。 |
| 矩形範囲（M） | 画像の上からでも任意の矩形を指定し、その範囲の切り抜き・切り取り・削除を行う。 |

囲み操作には共通部分があるが、画像上のドラッグで前者は画像を移動し、後者は範囲を作るため、両方を維持した。ツール名とツールチップで用途を明確にしている。既存のキー割当は変更しない。
