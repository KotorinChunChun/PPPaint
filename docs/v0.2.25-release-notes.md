# PPPaint v0.2.25

- キャンバスサイズの幅・高さに元の数値と変更量を表示します。増加は青、減少は赤で示します。
- 元のキャンバス境界は橙の破線、変更後の境界は青で表示します。切り取られる部分は内容を残したまま暗くし、元と変更後の両方を全体図に収めます。
- 左上・中央などの位置ラベルを外しました。各図のツールチップと読み上げ名は保持します。
- プレビューの青い境界をドラッグして変更できます。拡大図では１画素単位の調整ができ、全体図でも拡張・切り詰めできます。両端連動・縦横比固定、Ctrl／Shiftにも対応します。
- 拡大図は100×100の枠を維持し、倍率（Alt+V）を0.25～16倍で変更できます。映す画像範囲の画素数も表示します。

実キャンバスは適用まで変更しません。取消は元の画像を保持し、適用は１回のUndoで戻せます。
