# PPPaint v0.2.8

- 未保存確認の「保存せずに閉じる」はN（Alt+N）。Enterの既定は取消を維持する。
- Ctrl+Shift+Xで矩形範囲をキャンバスとして切り抜く。Ctrl+Xはコピーして削除する切り取り。C/Enterの切り抜きも維持する。
- パレットの選択色を青い枠で表示。ダブルクリックでそのスロットを編集する。右クリックの「この色を編集」と選択後の「色」（Alt+I）も使える。編集したパレットと描画色を記憶する。
- スポイトはIで開始し、キャンバス上をクリックして背景・画像・図形の合成色を取得する。採取後は元のツールへ戻り、Escでも解除する。選択中の図形があれば、その描画色にも反映する。
- 左下の寸法ダイアログは、画像自体の拡大縮小からキャンバスの余白追加・切り詰めへ変更。「両端を連動」（Alt+B）は中心を固定し、オフでは左上を固定する。縦横比固定（Alt+R）は独立して切り替えられる。
- 数値変更に合わせて、実キャンバスとダイアログ内の縮小プレビューを更新する。適用で1回のUndoへ記録し、取消では寸法・表示倍率・スクロール位置を戻す。
- 元画像の画素、図形の大きさ・線幅・文字サイズは変更しない。余白は現在のキャンバス背景色・透明設定を使う。寸法差が奇数pxの場合、右/下を1px多く増減する。

ツールバー1行目のキーは引き続きツールチップのみ。

[キー一覧と根拠](keyboard-shortcuts.md)、[検証記録](../dev/v0.2.8-validation.md)を参照。
