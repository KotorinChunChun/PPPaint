# KotorinToysから使う

PPPaintは画像を描画・編集するツールです。KotorinToysの一覧でPPPaintを選び、「起動」で画面を開きます。すでに起動している場合は同じ画面を表示します。「停止」で正常終了できるのは、作業を保存済みで処理中の操作がないときです。未保存の作業があるときはPPPaintで保存してから終了してください。

自動起動と常駐には対応していません。初期状態でもOSの自動起動予約を作成しません。

v0.2.35はスクリーンショット編集向けで、保存形式はPNG/JPEGです。保存画像には図形や情報隠しも合成します。作業中の文書があるときに「開く」を選ぶと、別ウィンドウで開きます。Ctrl+Vやキャンバスへのドロップで取り込んだ画像は、現在の画像に重ねます。いずれかに未保存の作業がある場合は管理用の停止要求を拒否します。旧版の`.pppaint`/`.chunpaint`は現行画面で開けず、v0.2.30からは起動引数や管理用の「開く」要求でも受け付けません。旧版でPNGへ書き出して利用してください。

このページは連携用の補足です。ホスト側の登録先や画面は今回の文書整備で再検証していません。単体起動は現行配布物の `Start-PPPaint.cmd` を使用します。

利用者向けの起動・編集方法は[README](../README.md)、開発・検証方法は[開発手順](development.md)を参照してください。
