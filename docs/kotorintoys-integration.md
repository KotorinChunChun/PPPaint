# KotorinToysから使う

PPPaintは画像の描画と編集を行うツールです。KotorinToysの一覧でPPPaintを選び、「起動」で画面を開きます。起動中のときは同じ画面を表示します。「停止」は作業が保存済みで処理中でないときに正常終了します。未保存の作業があるときはPPPaintで保存してから終了してください。

自動起動と常駐には対応していません。初期状態でもOSの自動起動予約を作成しません。

v0.2.31はスクリーンショット編集向けで、保存形式はPNG/JPEGです。画像・図形・情報隠しを焼き込みます。「開く」は作業中の文書がある場合に別ウィンドウを使い、Ctrl+Vやキャンバスへのドロップは現在の画像に重ねます。いずれかに未保存の作業がある場合は管理用の停止要求を拒否します。旧版の`.pppaint`/`.chunpaint`は現行画面で開けず、v0.2.30からは起動引数や管理用の「開く」要求でも受け付けません。旧版でPNGへ書き出して利用してください。

このページは連携用の補足です。ホスト側の登録先や画面は今回の文書整備で再検証していません。単体起動は現行配布物の `Start-PPPaint.cmd` を使用します。

利用者向けの起動・編集方法は[README](../README.md)、開発・検証方法は[開発手順](development.md)を参照してください。
