# PPPaint v0.2.22

- Ctrl+Vと貼り付けの主ボタンで、すぐに重ね貼りします。Ctrl+Shift+Vまたは隣の▼で重ねる／上／下／左／右を選べます。
- 新規の空キャンバスも、小さい画像を貼って縮小しません。必要な幅・高さだけ拡張します。▼の連結指定は新規文書にも適用します。
- ファイル▼・その他▼・重なり▼に加え、貼り付け方法を開く▼を配置しました。上部のキー表示は引き続きツールチップだけです。
- 四辺・四隅の外枠をドラッグしてキャンバスを切り詰め／拡張できます。Ctrlは対角側も同量変更、Escで取消。画像の画素を拡大縮小せず、余白追加と切り詰めを行います。
- 図形選択枠内の何もない場所、範囲内の空白、キャンバス外の作業余白のクリックで選択を解除します。グループ内の空白からドラッグした場合は、グループ全体を移動できます。
- その他▼／右クリックの「選択を画像に統合」、またはCtrl+Eで、選択図形を透過背景の１画像にします。番号の続き・背景・未選択図形を保持し、Undoで元の図形へ戻せます。

統合は選択図形の中で最前面だった位置へまとめます。非連続の重なりを選択すると、間にあった未選択図形との重なり方は変わります。ぼかし・モザイク・消しゴムを含める場合、統合内での効果対象は選択した図形です。画像保存後の再読込では元の図形編集を復元しません。

Ctrl+Eは [Photoshopの選択レイヤー統合](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/get-started-layers/merge-and-stamp-layers.html) に合わせた割当です。貼り付けメニューのCtrl+Shift+Vは今回のユーザー指定です。
