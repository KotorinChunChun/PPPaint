# PPPaint v0.2.21

キャンバスサイズ画面のプレビューを変更しました。

- 中央の全体図と、その周囲に四隅・四辺中央の８拡大図を表示します。
- 拡大図は100×100 DIP、25×25画像画素の４倍表示です。境界線は画像の外側に置き、端の１画素を隠しません。透明な部分は市松模様、キャンバス外は灰色で区別します。
- 幅・高さの手入力、１px刻みの増減、両端連動の切り替えで画面内の図を更新します。不正・未完成の入力では適用できません。
- 適用までは本体キャンバスの寸法・表示倍率・スクロール位置を変更しません。取消は編集前の状態を維持し、適用は１回のUndoで戻せます。

幅はAlt+W、高さはAlt+H、縦横比固定はAlt+R、両端連動はAlt+B。適用はAlt+SまたはEnter、取消はAlt+CまたはEscです。

今回、未保存の旧版は保持し、設定を複製して `Start-PPPaint-Parallel.cmd` から最新版を並行起動しています。通常の `Start-PPPaint.cmd` は従来の設定先を使うため、旧版を閉じた後に使用できます。
