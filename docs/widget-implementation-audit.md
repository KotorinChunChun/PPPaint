# ChunPaint ウィジェット実装監査

最終更新: 2026-08-30

UI上に配置済みの操作について、表示だけで終わっていないかを実装コードと照合する。状態は、実処理とUndo/Redoまで接続済みを「実装」、一部だけ動作するものを「部分実装」、イベント未接続を「未実装」とする。

## 実装済み

- 新規、開く、キャンバスへのインポート、保存、名前を付けて保存、終了
- Undo / Redoとキーボードショートカット
- 鉛筆、ブラシ6種類（油彩、水彩、マーカー、鉛筆風、エアブラシ、カリグラフィー）、消しゴム、塗りつぶし、スポイト
- テキストオブジェクトの挿入後編集、書体、サイズ、太字、斜体、下線、取り消し線、背景塗り、複数行、左・中央・右配置、移動、8ハンドル、回転、適用、キャンセル
- 色1・色2、パレット、色編集、線幅、不透明度
- 矩形選択、自由選択、選択範囲の移動、方向キー移動、8リサイズハンドル、回転ハンドル、適用、キャンセル、透明選択、選択範囲反転、表示レイヤーをコピー
- 切り取り、コピー、貼り付け、削除、トリミング、選択範囲の色反転
- サイズ変更、右/左90°回転、180°回転、左右/上下反転
- アクティブレイヤーの背景除去
- ズームイン、ズームアウト、100%へ戻す、25～800%倍率コンボ同期、ルーラー、グリッド線、ステータスバー表示、F11全画面表示、Esc復帰
- レイヤー追加、選択、表示切替、複製、削除、並べ替え、結合、名前変更、実サムネイル
- `.chunpaint`プロジェクト形式の保存・読込
- 画像のプロパティ表示
- 図形23種（ハート、稲妻を含む）、輪郭の有無、塗りの有無、色1・色2、線幅、不透明度、確定前プレビュー、確定後の再選択、移動、8ハンドル、回転、適用、キャンセル
- 上部の共有、フィードバック、アカウント、設定
- 表示設定（ルーラー、グリッド線、ステータスバー）と製品版数表示
- PNG、JPEG、BMP、GIF、.chunpaintのウィンドウへのドラッグ＆ドロップ読込
- デスクトップの背景設定（画面に合わせる、並べて表示、中央に表示）
- 可視レイヤー合成画像の1ページ印刷、印刷可能領域への縦横比維持配置、印刷プレビュー、Ctrl+P

## 部分実装

- サイズ変更: ピクセル指定と縦横比維持は実装済み。パーセント指定と傾斜は未実装。
- 画像ファイルへ既にラスタライズされた旧データ内のテキスト・図形は、編集可能オブジェクトとしては復元できない。
