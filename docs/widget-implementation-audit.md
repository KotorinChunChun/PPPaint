# ChunPaint ウィジェット実装監査

最終更新: 2026-08-29

UI上に配置済みの操作について、表示だけで終わっていないかを実装コードと照合する。状態は、実処理とUndo/Redoまで接続済みを「実装」、一部だけ動作するものを「部分実装」、イベント未接続を「未実装」とする。

## 実装済み

- 新規、開く、キャンバスへのインポート、保存、名前を付けて保存、終了
- Undo / Redoとキーボードショートカット
- 鉛筆、ブラシ6種類（油彩、水彩、マーカー、鉛筆風、エアブラシ、カリグラフィー）、消しゴム、塗りつぶし、スポイト
- テキスト挿入、書体、サイズ、太字、斜体、下線、左・中央・右配置
- 色1・色2、パレット、色編集、線幅、不透明度
- 矩形選択、切り取り、コピー、貼り付け、削除、トリミング、選択範囲の色反転
- サイズ変更、右/左90°回転、180°回転、左右/上下反転
- アクティブレイヤーの背景除去
- ズームイン、ズームアウト、100%へ戻す、25～800%倍率コンボ同期、ルーラー、グリッド線、ステータスバー表示、F11全画面表示、Esc復帰
- レイヤー追加、選択、表示切替、複製、削除、並べ替え、結合、名前変更、実サムネイル
- `.chunpaint`プロジェクト形式の保存・読込
- 画像のプロパティ表示
- 図形21種、輪郭の有無、塗りの有無、色1・色2、線幅、不透明度、ドラッグ中プレビュー

## 部分実装

- 選択: 矩形範囲と編集操作は実装済み。範囲のドラッグ移動、自由選択、透明選択は未実装。
- サイズ変更: ピクセル指定と縦横比維持は実装済み。パーセント指定と傾斜は未実装。
- テキスト: 入力と書式付き描画は実装済み。キャンバス上での挿入後編集、選択枠、変形は未実装。
