# ChunPaint ウィジェット実装監査

最終更新: 2026-08-31

UI上に配置済みの操作について、表示だけで終わっていないかを実装コードと照合する。状態は、実処理とUndo/Redoまで接続済みを「実装」、一部だけ動作するものを「部分実装」、イベント未接続を「未実装」とする。

C14時点のCore契約テストは124件成功、Debug|x64は警告0・エラー0。960px相当と最大化の実画面では、リボン、横長サムネイル、長名省略、固定操作ボタン、保存再読込後の所属図形を確認した。マニフェストは`PerMonitorV2`であり、WPFのレイアウト値はDIPで定義している。125/150/200%はOS設定を切り替えず論理DIP契約として確認し、実OS倍率の画像比較は残る検証として明示する。

## 部分実装

- PNG/JPEG/BMP/GIFの実ファイル往復、JPEGの透過不可・品質差、GIF減色、ディスク不足はWin2D／OS依存のため実機統合試験で確認する。
- 画像プロパティは画像DPIを保持し、ピクセル／インチ／センチメートルの表示単位を切り替えられる。
- 画像ファイルへ既にラスタライズされた旧データ内のテキスト・図形は、編集可能オブジェクトとしては復元できない。

## C6自動検証の入口

```powershell
pwsh -NoProfile -File dev/quality/Invoke-QualityGate.ps1
```

起動済みChunPaintのUIキャプチャーまで行う場合は、`-Capture -CaptureProcessId <PID>`を追加する。自動検証では壁紙設定や印刷確定を実行しない。
