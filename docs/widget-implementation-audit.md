# PPPaint ウィジェット実装監査

最終更新: 2026-09-02

UI上に配置済みの操作について、表示だけで終わっていないかを実装コードと照合する。状態は、実処理とUndo/Redoまで接続済みを「実装」、一部だけ動作するものを「部分実装」、イベント未接続を「未実装」とする。

## C31 起動障害回復監査

カーソルDLLのリソース不整合で `Microsoft.UI.Xaml.dll` が起動直後に fail-fast する環境を確認し、リソース読込例外をシステム矢印へフォールバックする契約を追加した。Debug／Release の smoke 起動でウィンドウ検出とプロセス生存を確認済み。

## 部分実装

- 画像プロパティは画像DPIを保持し、ピクセル／インチ／センチメートルの表示単位を切り替えられる。
- ブラシ9種の描画特性は実装済みだが、Paint代表画像とのピクセル差分による高精度再現判定は未実施。
- 画像ファイルへ既にラスタライズされた旧データ内のテキスト・図形は、編集可能オブジェクトとしては復元できない。

## C6自動検証の入口

```powershell
pwsh -NoProfile -File dev/quality/Invoke-QualityGate.ps1
```

起動済みPPPaintのUIキャプチャーまで行う場合は、`-Capture -CaptureProcessId <PID>`を追加する。自動検証では壁紙設定や印刷確定を実行しない。
