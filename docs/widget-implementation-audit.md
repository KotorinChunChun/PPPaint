# ChunPaint ウィジェット実装監査

最終更新: 2026-08-29

UI上に配置済みの操作について、表示だけで終わっていないかを実装コードと照合する。状態は、実処理とUndo/Redoまで接続済みを「実装」、一部だけ動作するものを「部分実装」、イベント未接続を「未実装」とする。

## 実装済み

- 新規、開く、キャンバスへのインポート、保存、名前を付けて保存、終了
- Undo / Redoとキーボードショートカット
- 鉛筆、ブラシ、消しゴム、塗りつぶし、スポイト、テキスト挿入
- 色1・色2、パレット、色編集、線幅、不透明度
- 矩形選択、切り取り、コピー、貼り付け、削除、トリミング、選択範囲の色反転
- サイズ変更、右/左90°回転、180°回転、左右/上下反転
- アクティブレイヤーの背景除去
- ズームイン、ズームアウト、100%へ戻す、グリッド線、ステータスバー表示
- レイヤー追加、選択、表示切替、複製、削除
- 画像のプロパティ表示

## 部分実装

- 選択: 矩形範囲と編集操作は実装済み。範囲のドラッグ移動、自由選択、透明選択は未実装。
- サイズ変更: ピクセル指定と縦横比維持は実装済み。パーセント指定と傾斜は未実装。
- テキスト: 入力と描画は実装済み。フォント、サイズ、太字、配置などの書式UIは未実装。
- レイヤー: 基本操作は実装済み。並べ替え、結合、名前変更、実サムネイル、プロジェクト形式は未実装。
- 表示: ズームスライダーは動作する。倍率コンボボックスとの同期とルーラーは未実装。

## 未実装

- 図形ボタン一式、輪郭スタイル、塗りスタイル、図形プレビュー
- ブラシ種類の選択メニュー
- レイヤーの並べ替え、下のレイヤーとの結合、名前変更
- ルーラー
- 上部のフィードバック、アカウント、設定
- Copilot相当の独自拡張入口
- 印刷、共有、壁紙設定

## 実装順

1. 図形、輪郭、塗り、ドラッグプレビュー
2. レイヤー並べ替え・結合・名前変更とサムネイル
3. テキスト書式とブラシ選択
4. ルーラー、倍率同期、設定、共有などの補助コマンド
