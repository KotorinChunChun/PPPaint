# PPPaint v0.2.15

- 太さを変更しただけで文字サイズなども変わる問題を修正。複数選択の設定は、対応する対象にだけ適用する。異なる値は「混在」と表示する。
- 文字入力中のEscで、内容を消さずに画像編集へ戻る。IME変換中のEscは変換操作を優先する。
- 下部の「全体」は表示中の状態を示し、ウィンドウのサイズや設定欄、画像寸法の変化に追従する。もう一度押すか倍率を手動変更すると解除する。キャンバス変更の取消では元の表示モードへ戻る。
- 選択対象の削除・切り抜き・回転後に設定欄を同期。描画設定の初期化は選択対象の図形を変更しない。
- ファイル一覧は単クリックで選択し、ダブルクリック/Enter/開く・保存ボタンで確定する。フォルダーの確定はその中へ移動し、保存名は保持する。手入力した名前は古い一覧選択より優先する。

[検証記録](../dev/v0.2.15-validation.md)を参照。
